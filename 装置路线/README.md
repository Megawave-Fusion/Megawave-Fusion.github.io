# 装置路线

按约束构型整理共性知识，具体装置的参数、加热配置和结果在对应章节内积累。

## 托卡马克

轴对称环形磁约束；分别管理常规与球形托卡马克资料。

平衡、电流维持、MHD、破裂、偏滤器和加热接口。

## 场反位形 FRC

紧凑环形磁拓扑路线，需记录形成、维持与具体场结构。

形成与合并、粒子轨道、动理学稳定性、NBI/RMF 接口和排热。

## 磁镜

开放磁力线约束路线，关注镜场与端部区域。

镜比、各向异性、损失锥、端损失、NBI/RF 与端部系统。

## 仿星器

通过外部线圈构建三维约束磁场的路线。

三维平衡、磁场优化、输运、快粒子、线圈制造与加热可达性。

## 其他路线

反场箍缩 RFP、球马克、Z-pinch、惯性约束和磁惯性约束分别登记。

不同路线使用各自的模型、性能定义、能量收支和装置档案。

## 装置档案的记录内容

机构与名称、参数日期、几何与磁场、燃料、加热/驱动系统、脉冲或运行时长、诊断、性能定义、来源与已知限制。对数值注明设计目标或实测值。

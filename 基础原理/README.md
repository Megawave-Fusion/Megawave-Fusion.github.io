# 基础原理

从粒子运动到燃烧与排热，聚变物理需要在不同尺度间保持同一套单位、守恒关系和测量口径。本页组织七个专题；各专题给出定义、推导、教学算例、适用条件与来源。学习时先建立模型，再用无量纲参数判断它是否适用，最后与装置可观测量相连。

## 聚变反应与能量收支

核反应释放能来自初末态静质量之差。D-T 每次反应约释放 17.6 MeV，其中约 3.5 MeV 由 alpha 携带、14.1 MeV 由中子携带。带电产物与中子有不同的沉积路径，因此聚变总功率、等离子体自加热和可回收工程热量需要分别列账。[NRL Plasma Formulary 2016，热核反应表](https://suli.pppl.gov/2016/course/NRL_FORMULARY_16.pdf)。

对热核 D-T，反应数率密度为 $R=n_Dn_T\langle\sigma v\rangle$。这里 $\sigma$ 是截面，而 $\langle\sigma v\rangle$ 已对速度分布平均；两者单位不同，前者是面积，后者是体积/时间。总功率为 $P_{\rm fus}=\int R E_{DT}\,dV$，必须把密度和温度剖面留在积分内部。束流、非热分布和不同离子温度会改变平均，不能只以一个电子温度代表反应物分布。[Fitzpatrick：Nuclear Fusion Reactions](https://farside.ph.utexas.edu/teaching/plasma1/Fusionhtml/node6.html)。

学习这一部分应能完成三项核算：核反应道与产物能量是否相符；燃料和杂质是否满足准中性；输入、储能变化、辐射与输运是否在同一边界内闭合。[聚变反应与燃烧](聚变反应与燃烧/README.md)给出相同粒子二分之一因子、配比极值、氦灰稀释和剖面积分的具体例子。

## 约束与性能指标

磁约束通过粒子轨道和集体平衡限制跨场损失；惯性约束在燃料迅速解体前利用短暂高密度产生足够反应；磁惯性路线则在压缩与磁化之间组合条件。三者需要不同的损失模型，不能直接按“放电时长”排序性能。[装置路线](../装置路线/README.md)进一步说明磁拓扑、驱动和工程代价。

能量约束时间常定义为 $\tau_E=W_{\rm th}/P_{\rm loss}$。若储能正在变化，$P_{\rm loss}=P_{\rm heat}-dW_{\rm th}/dt$；还需说明是否已经包含辐射。粒子约束、快粒子慢化和放电脉宽各描述不同过程。三乘积 $nT\tau_E$ 引用时必须给出密度物种、中心/平均温度、温度单位及是否同一时刻实现，不能把不同放电的最好数值相乘。[Wurzel 与 Hsu：Lawson 综述，§IV 的实验比较方法](https://arxiv.org/html/2105.10954v3)。

若用 $Q_p=P_{\rm fus}/P_{\rm ext}$，须明确 $P_{\rm ext}$ 是被吸收功率、注入边界功率，还是其他定义。电网消耗还涉及源效率与辅机；工程净电又涉及热循环。所谓“盈亏平衡”必须带上系统边界。温度高、脉冲长、增益高和净供电分别提供不同证据，均不应单独代替完整评价。

## 平衡与 MHD 稳定性

在静态、各向同性、忽略重力的单流体模型中，力平衡为 $\nabla p=\mathbf J\times\mathbf B$，并满足 $\nabla\cdot\mathbf B=0$ 与准静态 Ampère 定律。点乘磁场得到 $\mathbf B\cdot\nabla p=0$，所以压力沿磁力线不变；在适当嵌套磁面条件下可写为磁通函数。强流动、各向异性快粒子压强或三维磁岛会改变这一简化。

平衡只回答宏观力是否相抵；稳定性还要给定扰动及边界条件，研究其增长或衰减。理想能量原理中，满足约束的扰动若存在负势能变化，可指示该理想模型中的不稳定；电阻、碰撞、动理学共振和主动反馈属于不同的补充问题。稳定平衡也不保证输运小，微观涨落可以在宏观形状基本不变时带走热量。

[流体与磁流体力学](流体与磁流体力学/README.md)逐项推导磁压力与张力、磁通冻结、Grad–Shafranov 磁通约定及电阻重联，并附原始课程和论文。阅读时应同时检查压力是否包含所有物种、磁场是局域值还是参考值、真空和壁的能量是否计入。无量纲 $\beta=2\mu_0p/B^2$ 是热压与磁压之比，不是脱离几何与剖面的统一稳定性上限。

## 等离子体波与波粒相互作用

线性波分析从规定的平衡分布与 Fourier 约定出发，求介电响应、极化和色散。冷等离子体模型能说明许多截止与共振的位置，但没有速度分布的细节，不能单独给出实际热吸收和非热尾部。均匀介质的局域传播条件也不等于天线已经能把功率耦合进入目标区域。

Landau 共振比较波相速度与粒子的平行速度；回旋共振还涉及粒子回旋相位，典型形式为 $\omega-k_\parallel v_\parallel-l\Omega_s=0$。本式中 $\Omega_s=q_sB/m_s$ 为带符号角频率，$l$ 为整数；采用正频率约定的系统页面会另行说明极化与谐波符号。共振条件只是相互作用条件，净吸收或增长还由分布梯度、极化和阻尼决定。

[等离子体波](等离子体波/README.md)将 Langmuir、离子声、O/X、whistler 与 MHD 分支分开，并核对冷介电、功率与阻尼。[辅助加热](../辅助加热/README.md)再连接波传播、沉积、快粒子慢化和电流驱动。一个完整加热结论应说明发射功率、耦合功率、吸收对象与位置，而不只列发生器频率。

## 输运、边界与快粒子

跨磁面粒子、热与动量输运决定核心剖面如何响应源与损失。碰撞输运的局域闭合有自己的自由程条件；磁场几何带来的新经典输运、微不稳定性的湍流通量和中性粒子过程应分开建模，再组合为统一预算。有效扩散系数是对特定问题的描述，未必能移植到另一种扰动或几何。

在偏滤器构型中，核心损失经分离面进入 SOL，沿开放磁力线到达靶面。平行导热、鞘层加速、辐射、中性粒子和靶材响应共同决定局部负荷。边缘适量辐射可以帮助排热，核心杂质却可能损害反应率；优化目标必须同时考虑两区，不能简单把所有辐射归为有害。

[输运与边界](输运与边界/README.md)新增守恒、香蕉轨道、自举电流、湍流相位、台基、两点模型、鞘层与脱靶的连续讲解。快粒子部分同时讨论轨道与 Alfvén 共振，区分再分布、真正逸出和热背景沉积。这样才能把[加热](../辅助加热/README.md)、[诊断](../诊断控制/README.md)与[材料负荷](../腔体材料/README.md)放到同一个物理问题中。

## 欧姆加热与自加热

在简化标量电阻 MHD 中，$\mathbf E+\mathbf u\times\mathbf B=\eta\mathbf J$，点乘电流可得

$$
\mathbf J\cdot\mathbf E
=\mathbf u\cdot(\mathbf J\times\mathbf B)+\eta J^2.
$$

左边是场对带电介质的总功率密度，第一项可转为整体机械能，第二项才是此模型中的焦耳热。标量电阻条件下 $P_{\rm Ohm}=\int\eta J^2dV$；若动理学响应、各向异性或强射频电场重要，就需使用相应广义模型。[流体与磁流体力学：能量守恒与欧姆加热](流体与磁流体力学/README.md)。

高温弱耦合 Maxwellian 等离子体的经典电阻率大致随 $T_e^{-3/2}$ 降低（还含有效电荷和 Coulomb 对数），所以给定电流密度下欧姆热会随温度升高减弱。这解释了进入高温工况为何需要辅助加热，但不能把低温部分电离阶段也按同一幂律外推。[动理学与碰撞：经典热流与 Spitzer 电阻](动理学与碰撞/README.md)。

D-T 自加热由反应产生的 alpha 先形成快粒子分布，再向热背景传能。若近似全部沉积且外部热输入定义一致，自加热份额约为 $Q_p/(Q_p+5)$，所以主导自加热与完全不依赖外部热输入的点火不同。欧姆、射频/束流、alpha 沉积各自有功率通道；内部碰撞传能只能在物种之间转移，不能再次当成全系统额外输入。具体推导见[聚变反应与燃烧](聚变反应与燃烧/README.md)。

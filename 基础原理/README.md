# 基础原理

聚变反应、约束、平衡、波与粒子、输运和能量收支。

## 聚变反应与能量收支

D-T、D-D、D-He3 反应通道；反应截面与反应率；产物及能量分配。

记录燃料组成、温度分布假设、反应率数据来源；区分反应功率、外部注入功率和净电输出。

## 约束与性能指标

磁约束、惯性约束与磁惯性路线；粒子约束和能量约束；三乘积与增益。

每次引用 Q 都写明分子分母和系统边界；不同装置的设计指标与实验指标单列。

## 平衡与 MHD 稳定性

力平衡、磁面、压力和电流剖面；理想/电阻 MHD；宏观不稳定性。

记录二维/三维、轴对称、各向同性等假设；不要将一种构型的方程直接用于所有装置。

## 等离子体波与波粒相互作用

冷/热等离子体色散、截止、共振、模转换、阻尼与准线性扩散。

分别记录波频率、偏振、平行波数谱、种类组分及吸收通道；与各系统原理页互链。

## 输运、边界与快粒子

碰撞和新经典输运、湍流、边缘/SOL、杂质辐射、快粒子约束。

区分局域与全局模型；给出源项、损失项、剖面与守恒预算。

## 欧姆加热与自加热

欧姆输入和反应产物自加热是功率收支中的独立项。

与外部辅助加热分别记账；对自加热注明产物约束、沉积和损失假设。

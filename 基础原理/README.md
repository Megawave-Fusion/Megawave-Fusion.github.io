# 基础原理

从等离子体物理开始，建立阅读聚变科学与工程的共同基础。以下五个专题已补充定义、主要推导、算例、适用条件和就近来源；本页保留聚变层面的导航与后续研究问题。

| 建议顺序 | 专题 | 核心问题 |
| --- | --- | --- |
| 起点 | [等离子体基本概念](等离子体基本概念/README.md) | 温度与能量、分布函数、准中性、屏蔽、集体效应和尺度 |
| 粒子 | [单粒子运动](单粒子运动/README.md) | 回旋、漂移、磁矩、磁镜与绝热不变量 |
| 统计 | [动理学与碰撞](动理学与碰撞/README.md) | Vlasov、速度矩、闭合、库仑碰撞、弛豫和输运 |
| 集体扰动 | [等离子体波](等离子体波/README.md) | 色散、偏振、截止、共振和阻尼 |
| 宏观体系 | [流体与磁流体力学](流体与磁流体力学/README.md) | 双流体、MHD、磁通、平衡、能量和重联 |

## 聚变反应与能量收支

D-T、D-D、D-He3 反应通道；反应截面与反应率；产物及能量分配。

记录燃料组成、温度分布假设、反应率数据来源；区分反应功率、外部注入功率和净电输出。

## 约束与性能指标

磁约束、惯性约束与磁惯性路线；粒子约束和能量约束；三乘积与增益。

每次引用 Q 都写明分子分母和系统边界；不同装置的设计指标与实验指标单列。

## 平衡与 MHD 稳定性

静态标量压力模型中的力平衡是 $\nabla p=\mathbf J\times\mathbf B$，它只回答平衡是否成立。稳定性还需研究满足边界条件的扰动；输运和约束性能需要额外模型。

[流体与磁流体力学](流体与磁流体力学/README.md) 给出双流体到单流体的条件、Grad–Shafranov 方程的磁通约定、理想能量原理及电阻重联标度，并列出相关原始课程与论文。

记录二维/三维、轴对称、各向同性等假设；不要将一种构型的方程直接用于所有装置。

## 等离子体波与波粒相互作用

先由 [单粒子运动](单粒子运动/README.md) 理解回旋与漂移，再通过 [等离子体波](等离子体波/README.md) 中的线性响应连接到介电张量、偏振和色散。

新的波专题区分 Langmuir、离子声、O/X、whistler 与理想 MHD 分支；截止、冷共振和真实吸收分别讨论。局域色散关系并不直接给出天线耦合效率或装置中的沉积剖面。

分别记录波频率、偏振、平行波数谱、种类组分及吸收通道；与各系统原理页互链。

## 输运、边界与快粒子

[动理学与碰撞](动理学与碰撞/README.md) 建立分布函数、碰撞算子、速度矩、平均自由程和热流的基础。输运系数必须与碰撞性、磁场和闭合适用条件一起引用。

后续仍需专章展开新经典输运、湍流、边缘/SOL、杂质辐射和快粒子约束；本次基础正文不声称已覆盖这些完整理论。

区分局域与全局模型；给出源项、损失项、剖面与守恒预算。

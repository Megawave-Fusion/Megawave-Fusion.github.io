# 术语与缩写

> 状态：初版知识框架，待领域审核 · 更新：2026-09-09

| 缩写 | 中文 / 英文 | 使用注意 |
| --- | --- | --- |
| ICRH | 离子回旋共振加热 / Ion Cyclotron Resonance Heating | 与宽义 ICRF 频段概念区分 |
| ICRF | 离子回旋频段 / Ion Cyclotron Range of Frequencies | 不单凭频段判定吸收机制 |
| ECRH | 电子回旋共振加热 / Electron Cyclotron Resonance Heating | 系统页同时管理 ECCD |
| ECCD | 电子回旋电流驱动 / Electron Cyclotron Current Drive | 电流驱动指标单列 |
| NBI | 中性束注入 / Neutral Beam Injection | 注入功率与吸收功率分开 |
| NBCD | 中性束电流驱动 / Neutral Beam Current Drive | 记录电流与功率口径 |
| LHCD | 低杂波电流驱动 / Lower Hybrid Current Drive | 与 LHH 加热目的区分 |
| EBW | 电子伯恩斯坦波 / Electron Bernstein Wave | 模转换过程独立记录 |
| FRC | 场反位形 / Field-Reversed Configuration | 不与反场箍缩混淆 |
| RFP | 反场箍缩 / Reversed-Field Pinch | 独立装置路线 |
| MHD | 磁流体力学 / Magnetohydrodynamics | 需说明模型近似 |
| SOL | 刮削层 / Scrape-Off Layer | 与核心区划分一致 |
| PFC | 面向等离子体部件 / Plasma-Facing Component | 不等于整个真空室 |
| PWI | 等离子体与壁相互作用 / Plasma-Wall Interaction | 注明表面及入射条件 |
| Q | 增益 | 每次定义输入/输出和系统边界 |

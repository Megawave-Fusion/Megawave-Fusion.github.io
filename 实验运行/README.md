# 实验运行

试验计划、放电记录、验收与故障复盘。

## 试验计划与台架

需求、测试对象、仪器、步骤、参数扫描、判据与数据路径。

判据在试验前定义；记录测量不确定性和失败条件。

## 放电与运行记录

shot/run ID、配置、时序、加热波形、诊断、异常和结论。

链接原始数据与处理脚本；对时后再解释跨系统因果。

## 验收与标定报告

部件测试、系统联调、接口验收、重复性与长期稳定性。

以可测量判据和签审记录闭环；不将空模板视为已完成验收。

## 故障与经验复盘

事件时序、证据、根因假设、排查、修复和回归验证。

区分已证实原因与待验证假设，保留负结果。

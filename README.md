## 使用方式

每个类目一个主页面，各套辅助加热系统分别一个主页面。直接在页面内的相关章节积累资料，内容增长到确有必要时再拆分文件。

目录采用中文且不加编号；各目录保留 `README.md` 作为 GitHub 自动展示的首页，正文使用中文，保留必要的专业缩写和原始文献标题。

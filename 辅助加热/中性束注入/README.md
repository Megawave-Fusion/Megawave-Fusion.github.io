# 中性束注入（NBI / NBCD）

高速中性粒子进入等离子体后电离，并通过相互作用传递能量和动量。

## 原理与适用条件

- 正/负离子束
- 中性化
- 束衰减
- 快离子轨道
- 慢化
- 电流驱动和扭矩

对每种吸收或驱动机制记录假设、波/束参数、等离子体参数、来源和失效范围。

## 设备组成与接口

- 离子源
- 抽取/加速电极
- 中性化器
- 残余离子偏转与收集
- 束流管
- 低温泵
- 量热靶

每个部件建立规格、接口图、材料、冷却、电气/真空连接、供应来源与版本记录。

## 设计计算与仿真

- 束能与功率
- 束流组分
- 发散角
- 中性化效率
- 束几何
- 穿透与直穿损失
- 轨道和热负荷

保存输入剖面、坐标、单位、边界、网格和代码版本；给出收敛、功率预算与实验比较状态。

## 控制与保护

- 离子源/加速时序
- 高压击穿
- 束线真空
- 束流位置
- 热靶温度
- 抽气和冷却联锁

用信号名、单位、量程、判据依据、延迟、动作、复位条件和验证记录描述每项控制/保护。限值由具体设计确定。

## 测试与验收

- 束流与能量标定
- 束斑/发散测量
- 量热
- 中性化诊断
- 束线传输
- 快离子与沉积比较

逐项列测试对象、仪器与标定、工况、步骤、可测量判据、误差、原始数据位置和结论；未开展测试的条目标注待执行。

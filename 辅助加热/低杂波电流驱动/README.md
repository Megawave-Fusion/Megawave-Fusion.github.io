# 低杂波电流驱动（LHCD / LHH）

低杂频段波与电子相互作用，电流驱动与热沉积使用各自指标。

## 原理与适用条件

- 可达性
- 平行折射率谱
- 电子朗道阻尼
- 边缘耦合
- 谱演化与电流剖面

对每种吸收或驱动机制记录假设、波/束参数、等离子体参数、来源和失效范围。

## 设备组成与接口

- 微波源
- 功率分配
- 移相网络
- 波导
- 多波导口发射器
- 真空窗
- 负载和冷却

每个部件建立规格、接口图、材料、冷却、电气/真空连接、供应来源与版本记录。

## 设计计算与仿真

- 频率
- 平行折射率谱
- 边缘密度
- 波导相位
- 耦合与反射
- 射线/全波
- 动理学与电流剖面

保存输入剖面、坐标、单位、边界、网格和代码版本；给出收敛、功率预算与实验比较状态。

## 控制与保护

- 多通道幅相
- 反射功率
- 打火
- 窗口温度
- 边缘耦合状态
- 真空与冷却联锁

用信号名、单位、量程、判据依据、延迟、动作、复位条件和验证记录描述每项控制/保护。限值由具体设计确定。

## 测试与验收

- 通道幅相和谱标定
- 波导匹配
- 功率平衡
- 假负载
- 耦合扫描
- 电流驱动诊断比较

逐项列测试对象、仪器与标定、工况、步骤、可测量判据、误差、原始数据位置和结论；未开展测试的条目标注待执行。

# 离子回旋加热（ICRH / ICRF）

离子回旋频段的波加热；吸收路径依组分、波谱和工况确定。

## 原理与适用条件

- 少数离子加热
- 谐波加热
- 模转换
- 波粒共振
- 快离子分布与沉积

对每种吸收或驱动机制记录假设、波/束参数、等离子体参数、来源和失效范围。

## 设备组成与接口

- 射频源/功率放大器
- 传输线
- 匹配网络
- 馈通
- 天线与法拉第屏蔽
- 假负载
- 冷却

每个部件建立规格、接口图、材料、冷却、电气/真空连接、供应来源与版本记录。

## 设计计算与仿真

- 频率、组分与磁场
- 平行波数谱
- 天线加载
- S 参数
- 电压/电流
- 场与沉积
- RF 鞘层
- 热结构

保存输入剖面、坐标、单位、边界、网格和代码版本；给出收敛、功率预算与实验比较状态。

## 控制与保护

- 频率/功率/相位控制
- 反射功率
- 弧光
- 馈通真空
- 冷却
- 源与天线保护时序

用信号名、单位、量程、判据依据、延迟、动作、复位条件和验证记录描述每项控制/保护。限值由具体设计确定。

## 测试与验收

- 低功率网络分析
- 功率链标定
- 假负载测试
- 匹配与相位
- 部件热测试
- 等离子体加载与沉积比较

逐项列测试对象、仪器与标定、工况、步骤、可测量判据、误差、原始数据位置和结论；未开展测试的条目标注待执行。

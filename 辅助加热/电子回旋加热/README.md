# 电子回旋加热（ECRH / ECCD）

电子回旋频段的微波系统；加热与电流驱动分别评价。

## 原理与适用条件

- O/X 模
- 截止与共振
- 谐波选择
- 射线与束传播
- 吸收和电流驱动

对每种吸收或驱动机制记录假设、波/束参数、等离子体参数、来源和失效范围。

## 设备组成与接口

- 回旋管
- 高压电源
- 磁体
- 模式变换器
- 传输波导/反射镜
- 真空窗
- 极化器
- 发射器
- 负载

每个部件建立规格、接口图、材料、冷却、电气/真空连接、供应来源与版本记录。

## 设计计算与仿真

- 频率与谐波
- 偏振
- 波束腰与发散
- 发射角
- 传播可达性
- 功率沉积位置
- 传输损耗

保存输入剖面、坐标、单位、边界、网格和代码版本；给出收敛、功率预算与实验比较状态。

## 控制与保护

- 回旋管时序
- 发射镜控制
- 真空窗温度
- 杂散微波
- 反射功率
- 电源、磁体和冷却联锁

用信号名、单位、量程、判据依据、延迟、动作、复位条件和验证记录描述每项控制/保护。限值由具体设计确定。

## 测试与验收

- 束型与模式纯度
- 极化标定
- 窗口和传输损耗
- 指向重复性
- 功率计量
- 沉积位置比较

逐项列测试对象、仪器与标定、工况、步骤、可测量判据、误差、原始数据位置和结论；未开展测试的条目标注待执行。

# 电子伯恩斯坦波加热（EBW）

通过模转换研究向电子伯恩斯坦波输送功率的路线，独立记录转换链。

## 原理与适用条件

- O-X-B / X-B 转换
- 上杂共振层
- 入射角窗口
- 密度梯度
- 吸收

对每种吸收或驱动机制记录假设、波/束参数、等离子体参数、来源和失效范围。

## 设备组成与接口

- 微波源
- 极化与注入光学
- 波导/反射镜
- 发射器
- 边缘密度诊断
- 功率监测

每个部件建立规格、接口图、材料、冷却、电气/真空连接、供应来源与版本记录。

## 设计计算与仿真

- 转换层位置
- 密度梯度长度
- 偏振与角度
- 全波转换计算
- 转换后传播和吸收

保存输入剖面、坐标、单位、边界、网格和代码版本；给出收敛、功率预算与实验比较状态。

## 控制与保护

- 注入角和极化
- 边缘密度监测
- 反射和杂散功率
- 源、真空与热保护

用信号名、单位、量程、判据依据、延迟、动作、复位条件和验证记录描述每项控制/保护。限值由具体设计确定。

## 测试与验收

- 极化与角度标定
- 边缘剖面测量
- 转换效率误差预算
- 反射/吸收功率平衡
- 重复性

逐项列测试对象、仪器与标定、工况、步骤、可测量判据、误差、原始数据位置和结论；未开展测试的条目标注待执行。

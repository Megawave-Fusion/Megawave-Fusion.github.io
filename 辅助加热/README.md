## 系统间的接口与比较

比较时区分电网输入、源输出、传输末端、耦合到等离子体及最终吸收功率。记录注入位置、谱、时序、效率分母与误差，分别说明加热、电流驱动、启动和剖面控制目标。

电子伯恩斯坦波与螺旋波作为扩展专题，不预设其适用于所有装置。欧姆加热和自加热归入 [基础原理](../基础原理/README.md)。

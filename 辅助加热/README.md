# 辅助加热与电流驱动

辅助加热系统把电网能量经过源、传输、耦合和粒子相互作用转成等离子体能量；电流驱动还要维持有方向性的速度分布。选择系统时，先明确需要的是电子/离子加热、非感应电流、粒子与动量注入，还是局部剖面控制，再比较能否把功率送到目标位置。

- [离子回旋加热（ICRH / ICRF）](离子回旋加热/README.md)：离子回旋频段的波传播、吸收和设备链。
- [电子回旋加热（ECRH / ECCD）](电子回旋加热/README.md)：毫米波共振、定位沉积与局部电流驱动。
- [中性束注入（NBI / NBCD）](中性束注入/README.md)：中性原子穿透、电离快离子、慢化和动量源。
- [低杂波电流驱动（LHCD / LHH）](低杂波电流驱动/README.md)：慢波可达性、快电子尾和定向电流。
- [电子伯恩斯坦波加热（EBW）](电子伯恩斯坦波加热/README.md)：过密等离子体中的模转换、传播与吸收。
- [螺旋波加热（Helicon）](螺旋波加热/README.md)：聚变低杂频段快波及其与低温螺旋波源的区别。

## 系统间的接口与比较

### 统一功率口径

同一台系统至少有电网输入 $P_{grid}$、源输出 $P_{src}$、传输末端 $P_{launch}$、净耦合 $P_{cpl}$ 和目标等离子体吸收 $P_{abs}$。在可按单向稳态功率链描述时，

$$
P_{abs}=P_{grid}\eta_{src}\eta_{tr}\eta_{cpl}\eta_{abs}.
$$

所有功率用 W，各效率无量纲，并按相邻计量平面定义。对 NBI，链中还需显式包含中性化、束线损失和束停止；对 EBW，还需分解模转换。若有储能变化、多程反射或多端口耦合，必须写相应的时间依赖能量流，不能强行套单一串联公式。

这个分层说明为什么“回旋管/速调管额定功率”“注入功率”“电子加热功率”不能混用。以理想示例 $10$ MW 电网功率、效率 $0.5\times0.9\times0.8\times0.7$ 计算，目标吸收只有 $2.52$ MW；这些数字仅演示分母的作用，不是任何系统的实测效率。机构的系统总览适合识别技术链，具体性能仍应追溯到对应设备、工况与日期。[ITER：辅助加热系统](https://www.iter.org/machine/supporting-systems/external-heating-systems)

### 加热源、驱动电流和控制目标

能量进入等离子体后可能先成为快电子/快离子储能，再传给热粒子，或随粒子损失离开。单个物种能量方程中的加热项单位为 $\mathrm{W\,m^{-3}}$；电流密度为 $\mathrm{A\,m^{-2}}$，粒子源为 $\mathrm{m^{-3}s^{-1}}$，动量源为 $\mathrm{N\,m^{-3}}$。不能用一张“功率沉积图”替代全部源项。电子加热改变电子温度，电子离子能量交换再影响离子；这一交换速度和输运损失决定最终温度响应。

ICRH 的吸收对象取决于混合离子成分、频率和波模；ECRH 首先作用于电子；NBI 先产生快离子，其能量再按慢化过程分配；LHCD、EBW 和聚变 Helicon 的电子动理学响应又各不相同。系统之间可有协同，例如一个系统改变快粒子分布后影响另一个系统的吸收，但不能在未经计算时把分开测得的效率线性相加。[IAEA《Fusion Physics》，第 5 章中性束加热与电流驱动](https://event.ipp-hgw.mpg.de/event/1032/contributions/1480/attachments/715/1166/IAEA%20-%20Fusion%20Physics.pdf)

对稳态托卡马克电流，常写 $I_p=I_{Ohm}+I_{BS}+I_{aux}$，分别为感应、自举和辅助驱动贡献；这是一种电流分解，动态阶段还要解电流扩散。自举电流由压力梯度等条件产生，不能冒充外部系统直接驱动的电流。评价局部控制时，总安培数也不够，沉积峰值、宽度、位置和响应速度同样重要。[Poli 等：ECCD 理论及系统设计模型](https://pure.mpg.de/rest/items/item_3018972_4/component/file_3023894/content)

### 传播、吸收与证据

系统“可用”需要逐层成立：源能产生所需功率；传输与耦合能把能量送到等离子体；波或粒子能够到达目标区；相互作用把能量或动量交给目标粒子；最终剖面和控制效果满足目标。每层都有不同诊断：量热约束设备功率，边缘测量约束耦合，温度与快粒子诊断约束加热，内部磁场和电流扩散约束电流驱动。

尤其要区分“功率不再反射”与“核心已经吸收”，以及“温度升高”与“净驱动电流”。DIII-D 的 Helicon 原始实验将额外电子加热作为对照，目的正是排除温度改变电阻率造成的电流剖面变化；其方法说明不同证据需要互相支持。[Lestz 等，2026 年原论文](https://arxiv.org/html/2609.12474v1)

跨装置比较须注明磁场、密度、温度、几何、频率或束能、脉宽、注入谱及效率分母。论文中的设计预测、台架验证、等离子体实验和商业连续运行能力是不同层级。本文及五个扩充系统页已核对所引公式的量纲和示例，但未经过装置团队专家评审，也没有把未执行的测试写为已完成。

电子伯恩斯坦波和聚变 Helicon 各有适用边界，不能因能够在某些实验中传播或吸收而预设适用于所有装置。欧姆加热与自加热见 [基础原理](../基础原理/README.md)，波和碰撞基础见 [等离子体物理](../基础原理/README.md)。

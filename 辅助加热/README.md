# 加热功率与电流驱动总览

辅助加热系统把电网能量经过源、传输、耦合和粒子相互作用转成等离子体能量；电流驱动还要维持有方向性的速度分布。选择系统时，先明确需要的是电子/离子加热、非感应电流、粒子与动量注入，还是局部剖面控制，再比较能否把功率送到目标位置。

- [离子回旋加热（ICRH / ICRF）](离子回旋加热/README.md)：离子回旋频段的波传播、吸收和设备链。
- [电子回旋加热（ECRH / ECCD）](电子回旋加热/README.md)：毫米波共振、定位沉积与局部电流驱动。
- [中性束注入（NBI / NBCD）](中性束注入/README.md)：中性原子穿透、电离快离子、慢化和动量源。
- [低杂波电流驱动（LHCD / LHH）](低杂波电流驱动/README.md)：慢波可达性、快电子尾和定向电流。
- [电子伯恩斯坦波加热（EBW）](电子伯恩斯坦波加热/README.md)：过密等离子体中的模转换、传播与吸收。
- [螺旋波加热（Helicon）](螺旋波加热/README.md)：聚变低杂频段快波及其与低温螺旋波源的区别。

## 从功率链到粒子源与动态响应

### 统一功率口径

同一台系统至少有电网输入 $P_{grid}$、源输出 $P_{src}$、传输末端 $P_{launch}$、净耦合 $P_{cpl}$ 和目标等离子体吸收 $P_{abs}$。在可按单向稳态功率链描述时，

$$
P_{abs}=P_{grid}\eta_{src}\eta_{tr}\eta_{cpl}\eta_{abs}.
$$

例如 $\eta_{src}=P_{src}/P_{grid}$、$\eta_{tr}=P_{launch}/P_{src}$，其余两项同样按相邻功率相除；四个比值相乘时中间功率逐项约去，留下 $P_{abs}/P_{grid}$，得到上式。所有功率用 W，各效率无量纲，并按相邻计量平面定义。对 NBI，链中还需显式包含中性化、束线损失和束停止；对 EBW，还需分解模转换。若有储能变化、多程反射或多端口耦合，必须写相应的时间依赖能量流，使用相应耦合网络方程。

这个分层说明为什么“回旋管/速调管额定功率”“注入功率”“电子加热功率”对应不同计量边界。以理想示例 $10$ MW 电网功率、效率 $0.5\times0.9\times0.8\times0.7$ 计算，目标吸收只有 $2.52$ MW；这些教学数字演示效率分母的作用。机构的系统总览适合识别技术链，具体性能仍应追溯到对应设备、工况与日期。[ITER：辅助加热系统](https://www.iter.org/machine/supporting-systems/external-heating-systems)

### 加热源、驱动电流和控制目标

能量进入等离子体后可能先成为快电子/快离子储能，再传给热粒子，或随粒子损失离开。单个物种能量方程中的加热项单位为 $\mathrm{W\,m^{-3}}$；电流密度为 $\mathrm{A\,m^{-2}}$，粒子源为 $\mathrm{m^{-3}s^{-1}}$，动量源为 $\mathrm{N\,m^{-3}}$。各源项分别输入输运与电流模型。电子加热改变电子温度，电子离子能量交换再影响离子；这一交换速度和输运损失决定最终温度响应。

ICRH 的吸收对象取决于混合离子成分、频率和波模；ECRH 首先作用于电子；NBI 先产生快离子，其能量再按慢化过程分配；LHCD、EBW 和聚变 Helicon 的电子动理学响应又各不相同。系统之间可有协同，例如一个系统改变快粒子分布后影响另一个系统的吸收，联合效率应从共同演化的分布函数求出。[IAEA《Fusion Physics》，第 5 章中性束加热与电流驱动](https://event.ipp-hgw.mpg.de/event/1032/contributions/1480/attachments/715/1166/IAEA%20-%20Fusion%20Physics.pdf)

电流来自带电粒子的定向通量：物种 s 的分布满足 $n_s=\int f_s d^3v$，则 $j_{\parallel,s}=q_s\int v_\parallel f_s d^3v$。对共同的极向截面 A 积分，$I=\int_A j_\phi dA$；因电流密度可相加，稳态托卡马克的分解便为 $I_p=I_{Ohm}+I_{BS}+I_{aux}$，分别表示感应、自举和辅助驱动贡献。这里速度沿场投影与环向投影通过同一磁平衡转换，电流单位为 A。动态阶段还要演化电流扩散，自举项则由压力梯度和碰撞响应求取。评价局部控制时，还需沉积峰值、宽度、位置和响应速度。[Poli 等：ECCD 理论及系统设计模型](https://pure.mpg.de/rest/items/item_3018972_4/component/file_3023894/content)

### 传播、吸收与证据

系统“可用”需要逐层成立：源能产生所需功率；传输与耦合能把能量送到等离子体；波或粒子能够到达目标区；相互作用把能量或动量交给目标粒子；最终剖面和控制效果满足目标。每层都有不同诊断：量热约束设备功率，边缘测量约束耦合，温度与快粒子诊断约束加热，内部磁场和电流扩散约束电流驱动。

尤其要区分“功率不再反射”与“核心已经吸收”，以及“温度升高”与“净驱动电流”。DIII-D 的 Helicon 原始实验将额外电子加热作为对照，目的正是排除温度改变电阻率造成的电流剖面变化；其方法说明不同证据需要互相支持。[Lestz 等，2026 年原论文](https://arxiv.org/html/2609.12474v1)

跨装置比较须注明磁场、密度、温度、几何、频率或束能、脉宽、注入谱及效率分母。论文中的设计预测、台架验证、等离子体实验和商业连续运行能力是不同层级。本文按上述工况和计量边界比较各类加热系统。

电子伯恩斯坦波和聚变 Helicon 的传播与吸收随磁场、密度、温度和发射谱变化。欧姆加热与自加热见 [基础原理](../基础原理/README.md)，波和碰撞基础见 [等离子体物理](../基础原理/README.md)。

### 同样吸收功率为何有不同的热响应

比较两种加热器时，可先建立“快粒子库—热背景”模型。设吸收功率 $P_0$ 全进入快粒子，热化时间为常数 $\tau_s$，暂忽略逸出和热输运。由 $\dot W_f=P_0-W_f/\tau_s$、$W_f(0)=0$，乘积分因子后得到 $W_f=P_0\tau_s(1-e^{-t/\tau_s})$。热背景收到 $P_{f\to th}=W_f/\tau_s$，再积分得 $\Delta W_{th}=P_0[t-\tau_s(1-e^{-t/\tau_s})]$。两库相加始终满足 $W_f+\Delta W_{th}=P_0t$。

教学设定 $P_0=4$ MW、$\tau_s=0.2$ s，在开启后 0.1 s，快粒子库存为 0.3148 MJ，热化功率为 1.5739 MW，已进入热背景的能量为 0.0852 MJ。与直接向热电子沉积的同功率源相比，初期温升斜率较小，而关源后仍有尾随热化。把两套系统接入统一控制器时，应将这类动态状态量带入模型；稳态时两者热输入才趋于同一功率。这里的时间常数由实验或动理学计算确定，教学值用于展示动态因果。

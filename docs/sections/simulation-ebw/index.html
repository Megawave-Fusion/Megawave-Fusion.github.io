Section 6.13 · 连续阅读

电子伯恩斯坦波模拟

5 个条目草稿 · 待领域审核

EBW 模拟按电磁波入射、O-X/X-B 转换、热波传播、回旋吸收与电子分布演化组织；这些过程的尺度和所需方程不同。先修见电子伯恩斯坦波加热。

6.13.1O-X 转换窗口与有限微波束

MF000203

在截止层定义入射条件

O-X-B 计算先给频率、真空束腰/发散、偏振、发射位置及二维角度，再由磁平衡和边缘密度定位 O 截止与上杂层。最佳 O-X 条件使用截止附近总磁场和密度梯度，不宜直接用机器环向方向或镜面机械角代替。有限束包含一组角谱，即使中心射线处于最佳角，也只有其中一部分谱落在高转换窗口。

从一维估算推进到二维全波

平板解析转换率适合快速扫描和检查角度符号；束腰较小、截止面弯曲或边缘剖面显著二维时，应以 IPF-FDMC 等全波模型求反射和转换。Köhn 等针对 Pegasus 的研究表明天线前剖面形状显著影响转换，而不是仅由一个中心密度决定。比较应保持入射束功率和偏振一致，并积分透射/反射能流得到转换率。实验接口优先需要边缘密度及其梯度、束形和角度扫描；把整束设为一个最佳 \(N_\parallel\) 会系统性漏掉角谱失配。

对局部平板基准，可用 \(N_{\parallel,\mathrm{opt}}^2=Y/(1+Y)\)、\(Y=|\Omega_e|/\omega\) 检查角度窗口中心，同时要求 \(N_{\rm pol}=0\)，其中 \(N_{\rm pol}=\mathbf N\cdot(\mathbf B\times\nabla n_e)/|\mathbf B\times\nabla n_e|\)；所有量都取截止附近。随后再对整个束角谱积分，并说明边缘折射是否包含在从真空束到截止层的映射中。

来源：Köhn 等 2011，作者摘要；Urban 等 2011，§2.1 有限 Gaussian 束。

6.13.2X-B 转换、倏逝层和有限 Larmor 半径

MF000204

热波支如何出现

直接 X-B 依赖快 X 波、截止及上杂共振构成的传播/倏逝结构；O-X-B 则先产生慢 X 支，再在上杂附近连接 EBW。两条路线都需解析转换区，但边界条件和穿过的倏逝层不同。EBW 的垂直波长可达到电子回旋半径量级，FLR 响应是支撑这一热波支的组成部分。单纯冷张量在上杂层加数值阻尼，不能据此证明功率已变成可传播 EBW。

冷全波与动理学全波的分工

冷全波常用于 O-X 波形、束效应和转换窗口；X-B 与热波支需热介电响应、合适转换模型或动理学方法。Khan 等以 TASK/W1 一维有限元和积分介电张量同时处理 FLR、O-X-B 和谐波吸收，提供了可检查的一维热全波基准。装置问题可先用它检验平板转换物理，再用实际几何处理束传播。网格必须同时覆盖真空波长和最短热波长，且随网格/损耗参数变化核对反射、转换与吸收，避免把正则化损耗误认为转换效率。

在无真实耗散的转换基准中，应以入射、反射和各传播分支出射的能流检查平衡。若在上杂附近人为加入碰撞以消除奇点，要把这部分耗散单列，并扫描碰撞参数，判断所得结果是传播分支转换还是局部数值功率汇。

来源：Khan 等 2016，原期刊摘要；相关热波原理。

计算图解

按同一净功率链且忽略两次转换间额外损失时，\(\eta_{\rm OXB}=\eta_{\rm OX}\eta_{\rm XB}\)；每个转换控制域分别检查 \(P_{\rm in}=P_{\rm reflected}+P_{\rm out}+P_{\rm absorbed}\)。

按 O-X、X-B、热传播和电流分段检验。

6.13.3EBW 热射线、谐波吸收与代码选择

MF000205

转换区之后再启动射线

在离开强转换区、局部热波支可辨识且背景尺度允许几何光学时，GENRAY 的 EBW 热色散或 AMR 射线可计算波数、群速度和吸收位置。初始化必须记录转换后的分支、波矢和功率，不能把真空 O 波的波矢原样当成 EBW。群速度方向与波矢方向也可显著不同，轨迹图应标明能量流向。

色散与吸收保持一致

GENRAY 手册列出非相对论热与相对论电子响应及 O-X-B 初始化；选项需对应目标电子温度、谐波和代码版本。计算应跟踪 \(N_\parallel\) 沿路变化、各谐波吸收及剩余功率，防止把第一个经过的冷谐波面当作唯一沉积位置。AMR–LUKE 方案在热射线基础上继续求非 Maxwell 吸收，而有限束与转换损失需从前一环节传入。比较两种传播模型时先使用同一转换后入射数据、平衡和线性阻尼，再比较更复杂的分布反馈；转换算法差异不应混入芯部热射线的代码差异。

射线推进还应检查热色散根是否连续跟踪：靠近谐波或转换区域，局部求根跳到另一支可能制造假转向或假吸收峰。保存色散残差、波数和群速度连续性，并缩小步长复算，可在进入 FP 前发现此类数值问题。

来源：GENRAY 手册，概述、§4–5、§7.3；GENRAY 官方 EBW/FP 接口；Urban 等 2009，AMR–LUKE 原始工作。

6.13.4EBW 准线性吸收与电流方向

MF000206

吸收功率不直接决定电流

EBW 可在回旋谐波附近强烈吸收，但驱动电流还依赖平行动量不对称、俘获/通行电子和碰撞松弛。发射 \(N_\parallel\) 的符号不一定等于主要吸收处的符号；不同谐波和轨迹也可能给出相反电流贡献。因此应输出吸收加权的局部谱、速度空间扩散和有符号电流剖面，避免只报一个吸收百分比。

AMR–LUKE 与 GENRAY–CQL3D

Urban 等使用 AMR 与相对论反弹平均 LUKE 联合计算准线性电子分布、沉积和电流。GENRAY–CQL3D 也提供 EBW 波数据与 FP 分布连接，但应核对所用分支的响应和接口，而不是假定两套流程完全等价。比较需要统一碰撞、环向电场、俘获电子和径向输运设定。若只计算规定平衡上的稳态驱动电流，应将其传给电流扩散/平衡求解器后再讨论放电演化；小电流启动阶段的闭合磁面和粒子损失条件不能自动沿用已有闭合磁面上的反弹平均模型。

电流机制分析可进一步比较 Fisch–Boozer 型碰撞不对称与俘获边界附近的 Ohkawa 型贡献。在混合 \(N_\parallel\) 符号或不同谐波共同吸收时，电流方向应由有符号速度矩 \(j_\parallel=-e\int [p_\parallel/(\gamma m_e)]f\,d^3p\) 计算（此处 \(f\) 按动量空间归一），而不以一条中心射线判定。

来源：Urban 等 2011，§2.3–2.4、§4；CQL3D 官方 Purpose/Function。

6.13.5EBW 非线性转换与数值、实验核对

MF000207

提高入射幅度时检查新过程

线性转换给出小信号基准；提高场幅后，电子和离子响应可能改变转换区。Arefiev 等的一维/二维动理学研究发现高幅度 X 波可经参量过程散射成 EBW 和 LH 波，离子动力学影响局部场结构。此时线性转换系数固定、再把注入功率成比例放大的流程遗漏了反馈。PIC 可研究这些过程，但需要改变网格、时间步、粒子数和计算域，并用低幅度结果恢复线性色散与转换。

用不同测量约束不同环节

转换窗口可由发射角、偏振和边缘密度扫描约束；进入芯部的功率再用加热调制、辐射温度及吸收诊断检查；电流则另与磁测和非感应电流分析连接。先在同一剖面上完成线性全波、热射线和 FP 的接口检查，再加入密度波动或非线性过程。建议保存入射、反射、各出射分支和粒子吸收的功率；并列给出数值误差与边缘剖面不确定性，才能判断效率下降是角度失配、转换退化还是芯部吸收变化。

低幅度基准还可检查电场幅度按比例变化时，功率是否按幅度平方变化；偏离这一规律后再分析非线性频谱和粒子响应。这样得到的是给定输入剖面与波幅下的机制判断，而非把某一 PIC 算例的阈值换成整套装置的总功率上限。

来源：Arefiev 等 2016/2017，作者摘要；斯图加特大学 EBW 转换研究说明。

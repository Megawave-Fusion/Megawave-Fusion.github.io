10.1.4参考来源

MF000083

以下参考入口于 2026-09-09 核对。具体数值仍需核对原始资料的版本、工况与正文。

  • ITER 辅助加热系统：辅助加热概览；装置参数须按具体版本引用。

  • 马克斯·普朗克等离子体物理研究所：聚变装置类型：托卡马克与仿星器概念。

  • 国际原子能机构：聚变技术路线：聚变路线分类；概览中的发展愿景不作为性能证据。

  • 国际原子能机构：聚变装置数据库：装置检索入口；本库未批量导入数据库。

  • ITER 包层：包层与第一壁工程入口；注意设计版本。

  • ITER 诊断系统：诊断系统入口。

  • ITER 配套系统：配套工程系统分类。

  • ITER 燃料系统：燃料与循环子系统。

  • 马克斯·普朗克等离子体物理研究所：等离子体加热课程：加热与电流驱动教学入口。

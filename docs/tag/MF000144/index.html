Entry 3.2.14 · 专题

RF 鞘层、近场与杂质释放

MF000144资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

天线周围平行射频电场可驱动与材料表面连接的场线上的射频鞘层。鞘层具有非线性电流—电压关系，射频振荡可以整流成额外的直流势差，改变入射离子能量和表面热负荷，并促进杂质溅射。这条边缘通道与核心离子回旋共振吸收不同，因此只优化核心共振位置并不能保证面对等离子体部件兼容。Bobkov 等，Progress in reducing ICRF-specific impurity release in ASDEX Upgrade and JET，作者公开稿。

常用的一个驱动指示量是沿相关磁力线的 \(\int E_\parallel\,dl\)，单位 V。但它不能直接等同于实际整流直流鞘层电压：完整结果还依赖两端边界、鞘层阻抗、粒子响应、磁场入射角和局地等离子体条件。线性、冷、体介电模型加理想金属边界，通常未包含全部非线性鞘层物理；把所有衰减都放进人为碰撞率也不能自动替代鞘层模型。

工程上，电流带排列、相位与功率平衡、天线框架上的感应电流、限制器几何和磁连接共同影响近场。ASDEX Upgrade 三电流带天线的实验工作说明，通过设计和电气调谐降低相关近场及感应电流，可以减小 ICRF 特有的钨释放；该案例支持一种设计原则，不能把其最优功率比直接变成本系统通用设定值。Bobkov 等，First results with 3-strap ICRF antennas in ASDEX Upgrade，2016 年实验论文摘要。

评估时应把近场计算与红外热像、局地光谱杂质源、适用的电位或电流测量及核心杂质演化并列。表面发射率、观察角和视线积分会影响测量解释；核心杂质增加还含后续输运，不能仅从核心信号倒推出某一块天线表面的瞬时溅射率。降低反射、降低局部鞘层驱动和降低核心杂质是三个需要分别验证的目标。

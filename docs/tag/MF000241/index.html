相对最细值，最后两档变化分别为 5.51%、4.29%、1.50%。这是已经观察到的网格变化，不是严格误差上界，尤其不能称 1% 网格独立。图中保留一阶与二阶的完整变化；尖角最大电场还需圆角与局部加密，不能用于额定功率/击穿设计。

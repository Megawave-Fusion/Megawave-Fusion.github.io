多物理耦合与数据接口

MF000064草稿 · 待领域审核在连续正文中阅读

IMAS、OMAS 与 OMFIT 的层级

IMAS Data Dictionary定义 Interface Data Structures（IDS），规定数据含义、单位和坐标；访问层负责读写这些结构。ITER 2025 年的开放发布公告涉及基础设施和逐步发布的物理软件，应逐仓库核对许可及依赖。数据结构、模型接口和运行环境共同组成工作流。

OMFIT 的 STEP通过 OMAS 组织状态，将稳定性、输运、平衡和台基计算按步骤连接并保存历史。其安装说明明确指出，OMFIT 本体不包含模块调用的所有外部程序；可访问一个界面，不等于已经获得 EFIT、TRANSP 或其他求解器与数据库。软件目录、实际安装和输入数据是三份需要对应的清单。

层级 负责的工作 接口成功之后仍要检查什么
物理求解器 解给定方程、生成通量/源项/平衡等 方程项、闭合、守恒、分辨率和模型适用性
IMAS/IDS、OMAS 等数据表达 描述物理字段、坐标、版本和读写 源程序是否按字段定义填值、坐标变换和归一化是否正确
OMFIT/STEP 等工作流 准备输入、调用程序、调度迭代、保存状态 模块是否真正启用、收敛条件、失败传播及状态是否过期
HPC/容器/作业系统 提供依赖与计算资源 二进制、驱动、MPI、随机性与结果可重复程度

IMAS-Python 的 IDS validation检查时间模式及坐标维度等一致性。字段形状正确后，仍需另算功率积分、物种收支及方向约定，才能判断两段程序在物理上是否闭合。

获取与运行依赖

软件 本次核对的代码获取或许可 需要单独落实的部分
OMFIT / IMAS OMFIT要求用户协议并授予仓库权限；IMAS已发布多项开放组件 OMFIT 不附带所有外部程序；IMAS 许可按各基础设施/物理软件仓库与版本核对

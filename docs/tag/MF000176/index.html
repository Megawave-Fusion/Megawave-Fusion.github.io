粒子与连续分布的全局动理学

MF000176草稿 · 待领域审核在连续正文中阅读

GTC 与 Gkeyll 的模型边界

软件 主要方程与表示 合适的研究任务 选择时应区分的点
GTC 全局环形 gyrokinetic PIC，可用 \(\delta f\) 或 full-\(f\)，有混合电子等模型 全局湍流、快粒子与 Alfvén 模相关研究 选定电子与电磁模型，并扫描标记数、随机性和数值噪声；PIC 不表示逐圈解析完整回旋运动
Gkeyll 当前公开 GK 模块为 full-\(f\)、长波极限、模态间断 Galerkin 分布网格，静电 GK-Poisson 非 Maxwellian 分布、开场线与鞘层相关动理学问题 与其 Vlasov-Maxwell 模块、历史论文中的电磁扩展分开；实际可用功能以所选模块为准

GTC 的粒子标记和 Gkeyll 的分布网格带来不同的误差来源；比较时先统一电子模型、碰撞、场方程及边界。保留 full-f 并不取消所采用的低频或长波排序。Gkeyll 的鞘层教学例还需与包含电离、复合和辐射的实际边缘模型区分。

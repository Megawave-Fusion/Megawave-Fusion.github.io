Entry 3.2.11 · 专题

波吸收、快离子分布与碰撞传能

MF000143资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

ICRH 中“波被某物种吸收”和“该物种热温度上升”是两个步骤。少数离子或谐波共振可首先形成非 Maxwell 高能尾部，且垂直与平行速度方向的展宽不同。用一个等效温度代替整个分布，可能保留总能量却改变吸收、碰撞传能、轨道损失和诊断响应。Alcator C-Mod 的公开研究已比较快离子诊断与 full-wave/Fokker–Planck 模型，并报告分布各向异性的影响；这属于特定实验和诊断范围内的证据，不是任何装置都满足同一分布的证明。MIT PSFC，2006 年报告摘要，快离子电荷交换诊断及 AORSA/CQL3D 比较。

令局地分布函数满足 \(\int f_h\,d^3v=n_h\)，其中 \(n_h\) 为数密度（\(\mathrm{m^{-3}}\)），因此 \(f_h\) 的 SI 单位是 \(\mathrm{s^3m^{-6}}\)。在回旋平均、弹跳平均等近似适用时，可示意写成

\[ \partial_t f_h=C_h[f]+\mathcal Q_{\mathrm{RF}}[f_h] +S_h-\mathcal L_h, \qquad \mathcal Q_{\mathrm{RF}}[f_h] =\nabla_v\cdot(\mathbf D_{\mathrm{RF}}\cdot\nabla_v f_h). \]

\(h\) 标记被演化的共振粒子群；碰撞项、源和损失均须独立定义。此处用局地直角速度坐标展示准线性扩散结构，实际轨道平均坐标必须保留相空间 Jacobian。\(\mathbf D_{\mathrm{RF}}\) 的单位是速度平方每秒，其大小、方向和共振条件由波场、谱和轨道决定，不是任意指定的“加热系数”。准线性描述还要求适当的相位去相关；强相干俘获不能自动归入普通扩散。

full-wave 解出场及各物种响应，再形成准线性算子并演化分布；更新后的分布改变介电响应，需返回波方程迭代。在相同功率归一化、坐标和积分范围下，至少核对

\[ P_{\mathrm{RF},h}^{\mathrm{wave}} =\int d^3x\,d^3v\,\frac{m_hv^2}{2} \mathcal Q_{\mathrm{RF}}[f_h]. \]

左右两侧单位均为 W。差异可能来自轨道映射、谱截断、速度边界或功率归一化，不能单靠强制缩放掩盖。已有 AORSA/CQL3D 和 TORIC/CQL3D 耦合研究提供此类建模路线；是否适用本装置仍需核对有限轨道宽度、多共振物种和边界损失。作者研究摘要，2023 APS DPP：自洽 full-wave/Fokker–Planck 模型。

共振粒子能量还满足独立预算：\(dW_h/dt=P_{\mathrm{RF},h}+P_{\mathrm{src},h}-P_{h\to e}-\sum_iP_{h\to i}-P_{\mathrm{loss},h}\)，其中传能按从该粒子群流出取正。电子、离子分流取决于分布、背景温度和组分，没有普遍固定比例。波直接加热电子与快离子随后碰撞加热电子应分开记录；在总等离子体预算中，内部碰撞交换相互抵消，不能把它们再加一次当成新输入。Mayoral 等，JET 反转少数离子与模式转换实验，§1 的碰撞慢化及电子/离子传能讨论。

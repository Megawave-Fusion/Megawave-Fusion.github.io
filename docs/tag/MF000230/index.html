Entry 6.9.2 · 专题

单电流带的回流路径与谐振近似

MF000230草稿 · 待领域审核在连续正文中阅读

先闭合电流，再讨论场

最小三维模型包含一条带、馈入间隙或同轴线、短路连接和接地腔。只放一块悬浮矩形金属再加电压，可能改变回流与电容。网格先解析带边、馈电间隙、短路和开口；比较端口阻抗、表面电流及开口场，而不只看远处波纹。TOPICA 原论文同时处理带、腔体、屏与同轴馈电，适合作为几何完整性的参照。

电尺寸较小的电路起步模型可写为

\[ Z_s=R_{\rm load}+R_\Omega-i\omega L+\frac{i}{\omega C},\qquad \omega_0=\frac1{\sqrt{LC}}. \]

这里采用 \(e^{-i\omega t}\)、RMS 电压电流，\(L,C\) 是提取/拟合的等效参数，不是材料常数。教学取 \(L=100\) nH、\(f_0=50\) MHz，得 \(C=101.32\) pF。若带上电流幅相明显变化，就改用分布传输线或三维场；短路端、电容调谐和等离子体负载共同决定电流形状，不把所有 strap 都当自由空间半波振子。

谐振使输入虚部过零，未必使实部等于 50 Ω；电路通过还要检查带、间隙和馈通上的峰值电压。可对照 WEST 模型的电容与调谐定义。

Entry 3.7.3 · 专题

设计计算与仿真

MF000048资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

模型首先应回答发射的是哪一支波。冷全波计算可识别边缘耦合、极化与分支，但电子加热和电流驱动需要合适的热/动理学响应。传播足够缓变时，热射线模型可求波路和阻尼；在天线近场、截止附近或显著散射时，应使用更完整的波动模型，并把其输出与核心传播模型衔接。

功率预算可写为

\[ P_{in}-P_{out}-P_{refl}=P_{structure}+P_{plasma},\qquad P_{plasma}=P_{core}+P_{edge}+P_{other}. \]

各项均为 W，第一式需在一致的稳态计量面定义；瞬态还要加电磁/热储能变化。\(P_{plasma}\) 不能仅凭低反射就全部赋给核心电子：边缘吸收及其它通道可能占有份额。第二式中的分项应以模型和诊断约束，不得因能量缺口而任意填一个“耦合效率”。

数值预测要改变射线数、发射角谱、平衡与动理学剖面，检查沉积位置和积分电流是否稳定。多程吸收尤其依赖壁面处理；假定全反射无损会给出过于乐观的上限。当前 DIII-D 原论文也明确把首程预测和假设完全多程吸收的上限分开，未将二者混称为测量值。Lestz 等，Calculation of the Driven Current Profile

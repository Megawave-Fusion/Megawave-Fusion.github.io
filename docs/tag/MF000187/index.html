Entry 6.9.5 · 专题

ICRH 网格、谱收敛与测量量对照

MF000187草稿 · 待领域审核在连续正文中阅读

分开推进数值收敛

波求解至少分别增加径向网格、极向模数和天线环向谱覆盖，跟踪各组分吸收份额、峰位置及积分功率。弱吸收时多次传播和模间耦合使谱需求增加；只看场图平滑不足以认定收敛。天线有限元模型还需改变网格、计算域和吸收层厚度，检查 S 矩阵及参考面功率是否稳定。HFSS 实现中材料张量和时间谐波约定不同，转换错误可能直接改变耗散符号。

按测量过程检验

天线端先比反射、带电流或馈电电压，再比耦合电阻随边缘密度的变化；芯部先比调制响应及受热组分，快尾问题再用能谱、快粒子诊断和轨道损失约束。此处建议的验证顺序是：相同几何的端口基准、同一物理近似的波代码比较、分布和轨道前向诊断，最后加入输入不确定性扫描。组分浓度与边缘密度的误差应单独传播，不能用调整一个“有效吸收率”同时拟合所有观测。

代码间比较还可先采用均匀或一维剖面，核对冷波长、极化和无耗散极限的能流；再逐次打开热响应、真实几何和非 Maxwell 分布。每一步保留相同输入，便于把差异定位到新增物理，而非几何或归一化。

来源：Brambilla 1999，§1 与 §9；Tierens 等 2019，验证对象；Maquet 等 2023，§2–4。

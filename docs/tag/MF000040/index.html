EBW 色散与 O-X-B 转换

MF000040草稿 · 待领域审核在连续正文中阅读

为什么能越过普通电子回旋波的密度限制

冷介电模型包含 O、X 等电磁分支，却丢掉了粒子在有限回旋轨道上采样波场的效应。保留有限温度后，色散在电子回旋谐波之间出现 Bernstein 分支。其性质依赖 \(k_\perp\rho_e\)，其中 \(\rho_e=v_{te}/\Omega_e\)、\(v_{te}=\sqrt{2T_e/m_e}\)，此处 \(T_e\) 以 J 表示。\(k_\perp\) 为 \(\mathrm{m^{-1}}\)、\(\rho_e\) 为 m；它们的乘积无量纲。Fitzpatrick：温等离子体垂直传播，图 7.9

有限回旋半径怎样进入色散，可以从最简单的垂直静电波推起。取均匀磁场、无碰撞 Maxwell 电子、静止离子及 \(k_\parallel=0\)，令电势扰动为 \(\phi_1e^{ik_\perp x-i\omega t}\)。在未扰动轨道 \(x=X+\rho\sin\theta\) 上，将波因子展开为 \(e^{ik_\perp\rho\sin\theta}=\sum_\ell J_\ell(k_\perp\rho)e^{i\ell\theta}\)；线性 Vlasov 方程每个谐波的轨道积分便带分母 \(\omega-\ell\Omega_e\)。再对垂直 Maxwell 分布积分，使用 \(\int_0^\infty ue^{-u^2}J_\ell^2(au)du=e^{-a^2/2}I_\ell(a^2/2)/2\)，并把正负谐波配对，Poisson 方程给出

\[ \epsilon_L=1-\frac{2\omega_{pe}^2e^{-b}}{b} \sum_{\ell=1}^{\infty} \frac{\ell^2I_\ell(b)}{\omega^2-\ell^2\Omega_e^2}=0, \qquad b=\frac{k_\perp^2v_{te}^2}{2\Omega_e^2}. \]

这里 \(J_\ell\)、\(I_\ell\) 分别是第一类普通、修正 Bessel 函数，\(\Omega_e=eB/m_e>0\)。这是垂直、静电极限的 Bernstein 色散；有限 \(k_\parallel\) 和相对论效应另行加入热响应。式中回旋谐波的分母保留下来，且色散不再要求电磁 O 模的 \(N^2=1-\omega_{pe}^2/\omega^2>0\)，因而可在 O 模截止密度之上存在传播解。当 \(b\to0\) 时只有 \(I_1(b)\simeq b/2\) 留下，方程退为 \(1-\omega_{pe}^2/(\omega^2-\Omega_e^2)=0\)，连续回到上杂频率；这也检查了热色散的冷极限。Fitzpatrick，垂直热色散与 Bernstein 分支

EBW 在过密区的传播路径由热色散和背景剖面决定。EBW 的波矢、群速度和吸收对密度、温度及磁场变化敏感，也可能先在外层谐波吸收。其准静电分支依赖等离子体响应，无法在真空作为同一支波远程传播，所以必须通过电磁波与 EBW 之间的模转换来注入或观测。Urban 等，§1–§2

O-X-B 与 X-B 转换

O-X-B 路线先从低密度侧注入适当斜角和偏振的 O 模，在接近 O 模截止的区域转换到连接慢 X 支的波，再在上杂共振附近转换为 EBW。上杂角频率为

\[ \omega_{UH}^2=\omega_{pe}^2+\Omega_e^2. \]

频率单位均为 \(\mathrm{rad\,s^{-1}}\)。上式可由刚才的 \(b\to0\) 色散乘以 \(\omega^2-\Omega_e^2\) 后移项得到；它描述垂直电子振荡同时受到电荷分离恢复力与磁场回旋力作用。O-X 与 X-B 两步转换的位置、敏感参数及损失分别计算。直接 X-B 注入则依靠 X 支通过适当的截止—共振结构耦合，倏逝层厚度对效率非常重要，直接影响转换功率。Urban 等，§2.1

对于局部一维平板、近平面波、适当磁场/密度梯度几何的 O-X 转换，定义 \(Y=\Omega_e/\omega\)、\(\mathbf N=c\mathbf k/\omega\)，最佳条件为

\[ N_{\parallel,opt}^{2}=\frac{Y}{1+Y},\qquad N_{pol}=0. \]

这里 \(N_{pol}\) 是沿 \(\mathbf B\times\nabla n_e\) 方向的折射率分量，与密度梯度方向的波矢分量分别定义。\(Y\) 与全部分量应取 O 模截止附近的局部值。若 \(Y=0.5\)，则 \(|N_{\parallel,opt}|=1/\sqrt3\simeq0.577\)；实际真空发射角还需通过边缘折射和真实几何映射，由该映射求机械镜角。Urban 等，式 (1)

最佳角的来源是两个冷波分支在 O 截止处的匹配。记 \(X=\omega_{pe}^2/\omega^2\)，忽略离子响应时平行介电量是 \(P=1-X\)；O 截止有 X=1。此处非共振圆偏振分量 \(L=1-X/(1+Y)\)，所以 \(L=Y/(1+Y)\)。在 \(N_{pol}=0\) 的转换平面中，令慢 X 分支的截止 \(N_\parallel^2=L\) 与 P=0 重合，就得到 \(N_{\parallel,opt}^2=Y/(1+Y)\)。偏离这个值会分开两支的转向点，在它们之间产生有限的倏逝间隙；下面的效率公式量化这一间隙。

转换后吸收和电流驱动

EBW 到达电子回旋谐波附近时可强烈吸收。有限 \(k_\parallel\) 与相对论效应使共振满足 \(\omega-k_\parallel v_\parallel=s\Omega_e/\gamma\)，因而冷谐波面只是参考位置。吸收后能否产生电流，还要看速度分布不对称、碰撞和捕获电子。EBW 的 \(N_\parallel\) 可沿路显著演化，发射时选定方向并不意味着吸收处谱保持原样。对于过密球形托卡马克，EBW 是有吸引力的候选方案，系统效率还包含转换、传输与电源效率。UKAEA：STEP EBW 电流驱动会议摘要，2023 年登记

由截止面与混杂面计算转换层的位置

O 模截止满足 \(\omega_{pe}=\omega\)，故 \(n_O=\epsilon_0m_e\omega^2/e^2\)。上混杂层满足 \(\omega^2=\omega_{pe}^2+\Omega_e^2\)，逐项移项后得到 \(n_{UH}=n_O(1-Y^2)\)，其中 \(Y=|\Omega_e|/\omega\)。若局部磁场变化小、密度按 \(n(x)=n_*e^{x/L_n}\) 增长，两个密度面的间距为 \(\Delta x=L_n\ln(n_O/n_{UH})\)。这把频率、磁场和密度梯度联系到具体空间尺度。

取教学频率 28 GHz，选择磁场使 \(Y=0.5\)，即约 0.5001 T。O 截止密度为 \(9.7251\times10^{18}\) m⁻³，上混杂密度为 \(7.2938\times10^{18}\) m⁻³；\(L_n=20\) mm 时，两面的间距为 5.754 mm。若整个密度剖面增大 10%，固定密度面沿 x 方向移动 \(-L_n\ln1.1=-1.906\) mm。转换窗口的控制因而要跟踪边缘密度和梯度，毫米级层位移动就会改变波束与转换区的相交位置。这里只计算层位；转换份额另由角度、极化和完整波场求得。

推导起点与参考位置：Urban 等 2011，EBW survey，§2.1，式 (1)–(3)。

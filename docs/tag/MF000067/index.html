Entry 7.1.1 · 专题

磁体与电源

MF000067资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

场、储能与机械力

磁体用电流建立磁场，导体和支承同时承担电磁载荷。理想长螺线管近似 \(B\simeq\mu_0n_{\rm turn}I\)，其中 \(n_{\rm turn}\) 为每米匝数；真实环形及三维线圈必须计算几何、回线、互感和铁磁材料。在线性、等效单回路条件下，

\[ W_m=\frac12LI^2,\qquad V=L\frac{dI}{dt}+RI. \]

\(L\) 用 H，\(I\) 用 A，储能用 J，电压用 V。多线圈耦合时应改用 \(W_m=\tfrac12\mathbf I^{\mathsf T}\mathbf L\mathbf I\)。同样电流下，磁体电感不同，储能与停机时需要处理的能量就不同。教学例取 \(L=1\,\mathrm H,I=20\,\mathrm{kA}\)，得 \(W_m=200\,\mathrm{MJ}\)；若电流以 \(1\,\mathrm{kA\,s^{-1}}\) 上升，仅感应项就需要 1 kV。稳态电压很小不意味着磁体没有储能。

真空磁场能量密度为 \(u_B=B^2/(2\mu_0)\)，单位 \(\mathrm{J\,m^{-3}}\)，也给出磁压力的典型尺度 Pa。取 \(B=10\,\mathrm T\) 得约 39.8 MPa。这个数不是线圈中最大应力；导体、线圈盒与支承的受力路径和几何会形成不同应力分布。场强加倍使这一尺度增加四倍，说明“提高磁场、缩小装置”必须同时核算结构。ITER 的导体采用超导丝、铜与钢套管组合，是电、热、机械功能共同设计的实例。ITER《Magnets》，导体与线圈系统说明。

常导、超导与失超保护

常导线圈的焦耳功率为 \(I^2R\)。超导材料则只在特定温度、磁场、电流密度和应变条件下维持低电阻状态，电流引线、接头、交流损耗与制冷依然消耗能量。失超指局部或整体退出超导状态，电阻出现后局部 \(I^2R\) 热会继续升温。保护的物理任务是识别异常并把储能分配到设计允许的耗散路径，避免热点、绝缘过压和压力失控；具体阈值不能跨磁体照搬。

若教学模型中电感为 \(L\)、放电电阻为 \(R_d\)，忽略电感变化和其他电阻，有 \(I(t)=I_0e^{-tR_d/L}\)。增大 \(R_d\) 可缩短 \(L/R_d\)，但初始电压 \(I_0R_d\) 也增大，故快速释能与绝缘要求相互制约。这是简单电路推导，真实失超需耦合电路、传热与超导转变，不能由指数衰减直接判断安全。ITER 的低温系统还配置氦库存回收体系，用以处理失超等状态下的介质响应。ITER《Cryogenics》，冷源、库存与分配系统。

电源不仅给出额定电流，还决定爬升速度、纹波、反馈带宽和故障时可控性。装置一般区分连续辅助用电和脉冲磁体、加热负荷；整流与变换环节的效率、无功、谐波及电网峰值约束要进入系统分析。ITER 的稳态配电与脉冲供电分开设计，是研究装置的具体实现，不能作为未来电站净输出的直接估计。ITER《Power supply》，两类配电系统。

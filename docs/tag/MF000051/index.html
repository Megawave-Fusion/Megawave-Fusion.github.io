Entry 3.7.6 · 专题

文献与案例

MF000051资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

截至本页核验日，不能再沿用早期“完全没有聚变 Helicon 电流驱动证据”的说法。Lestz 等，arXiv:2609.12474v1，2026-09-11 报告 DIII-D 的 476 MHz 实验。其电流分析采用约 370 kW 耦合功率，推断 \(\rho<0.2\) 内驱动电流约 \(20\pm10\) kA；该数值来自诊断约束重建与其它电流源相减，不是独立电流表直读。论文明确指出外围重建振荡使全截面积分不可靠，亦不能区分不完全吸收和较低驱动效率。这是特定 L 模核心工况的原理验证，尚不等于反应堆离轴高效率目标已经实现。

本轮读取该预印本的正文与诊断/硬件附录，并检查 PRL 记录；这里的精确数值按上述 v1 定位，不混合不同版本。低温源的基础边界另据 UCLA 实验室资料。

原有 通用原子 DIII-D 升级历史资料 保留作为历史设计入口，本轮未读取其全文，也不把其规划功率或效率预期当作最新实测结果。本团队尚未开展文中装置的独立实验复现。

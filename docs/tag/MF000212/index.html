Helicon 模型核验与加热、电流实验的闭环

MF000212草稿 · 待领域审核在连续正文中阅读

给每一级模型独立的比较量

低温源先比较天线负载与磁探针波幅、相位、轴向波长，再比较吸收分布和密度。不同天线的比较必须固定尺寸、频率、密度与馈电计量面；大体积圆柱源论文发现的耦合排序随设定条件和密度剖面改变，不能写成通用最优天线。Chang 等原作者研究。调整有效碰撞率后应留下校准记录，并用另一组独立工况检验。

高温装置分开检验热源与电流源

对 RF 调制，先计算波吸收，再接入热输运生成温度时序，并对模拟和实测施加相同反演过程。对电流驱动，要扣除欧姆、自举、NBI 和 EC 电流，同时传播平衡与电导率误差。只观察升温或环电压下降，无法把加热导致的电阻变化与非感应电流分开。

截至核验日的实验约束

2026-09-11 的 DIII-D 作者预印本报告了芯部电子加热与 helicon 电流驱动证据，采用等效 ECH 对照、MSE 约束平衡及电流源相减；在 \(\rho<0.2\) 积分获得 \(20\pm10\) kA，GENRAY 对应预测 21 kA。作者说明外层重建振荡使全半径总电流不确定，多程吸收也尚未充分量化。Lestz 等预印本与方法。因此已有结果约束的是指定 L 模工况的原理验证；反应堆高压力、离轴高效率仍需在对应条件下检验。

报告中应同时保存端口与耦合功率、单程与多程假设、热源宽度、局部与积分电流及误差，避免用一个“效率”混合多个计量面。

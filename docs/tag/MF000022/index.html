Entry 3.3.1 · 专题

原理与适用条件

MF000022资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

共振位置与速度选择

取电子电荷为 \(-e\)，\(e>0\)，定义正的电子回旋角频率 \(\Omega_e=eB/m_e\)。非相对论、无平行多普勒频移时，\(s\) 次谐波满足 \(\omega=s\Omega_e\)；对热电子和斜入射波，真正的条件是

\[ \omega-k_\parallel v_\parallel=\frac{s\Omega_e}{\gamma},\qquad \gamma=(1-v^2/c^2)^{-1/2}. \]

\(\omega\) 和 \(\Omega_e\) 的单位为 \(\mathrm{rad\,s^{-1}}\)，\(k_\parallel\) 为 \(\mathrm{m^{-1}}\)，速度为 \(\mathrm{m\,s^{-1}}\)，\(B\) 为 T。\(s\) 是正整数。固定频率下，共振条件同时选择磁场位置与电子速度，因而冷共振面不是完整的功率沉积面。相对论回旋频率降低和 \(k_\parallel v_\parallel\) 可以使吸收发生在冷共振面的另一侧或形成展宽；应沿实际波束计算，不能用一个固定“温度修正百分比”代替。Poli 等，理论背景 §2.2、式 (15)–(20)

由基本常数得到 \(f_{ce}=\Omega_e/(2\pi)\simeq27.9925 B[\mathrm T]\,\mathrm{GHz}\)。所以 140 GHz 在 2.50 T 附近对应二次谐波；170 GHz 的基频冷共振磁场约为 6.07 T。这是频率—磁场换算，不是整台装置轴上场的指定值；托卡马克场沿大半径变化，斜入射还包含上述频移。

O/X 模与密度截止

在冷、均匀、无碰撞、严格垂直传播的近似下，O 模有电场平行于背景磁场，满足

\[ N_O^2=1-\frac{\omega_{pe}^2}{\omega^2},\qquad \omega_{pe}^2=\frac{n_e e^2}{\epsilon_0m_e}. \]

\(N=ck/\omega\) 无量纲，\(n_e\) 为 \(\mathrm{m^{-3}}\)。O 模在 \(\omega_{pe}=\omega\) 截止；140 GHz 对应 \(n_{e,O}\simeq2.43\times10^{20}\,\mathrm{m^{-3}}\)。这只是该频率的冷 O 模截止密度，不能直接套给 X 模，也不保证在截止以下就一定吸收充分。X 模的冷色散为 \(N_X^2=RL/S\)，\(S=(R+L)/2\)，因此它有自己的左右旋截止和上杂共振。斜入射时两支本征模通常为椭圆偏振，“O/X”沿连续的本征分支定义，不能仍把电场简单画成严格平行/垂直。Fitzpatrick，冷等离子体色散式 (5.44)–(5.55)

传播可达性、谐波吸收和极化匹配必须一起满足。波遇到截止会反射，偏振错误会把功率分到另一支波；即使通过共振区，温度、路径长度或谐波耦合不足仍可能留下大量未吸收功率。

为什么能够驱动电流

斜入射使共振偏向某一符号的 \(v_\parallel\)。在典型 Fisch–Boozer 机制中，选择性增加这群电子的垂直能量，改变其碰撞松弛速度，最终产生分布的不对称。电流密度由 \(j_\parallel=-e\int v_\parallel\delta f\,d^3v\) 给出，单位 \(\mathrm{A\,m^{-2}}\)。高能电子碰撞较弱有利于驱动，但共振选得过远，参与吸收的粒子会太少；捕获粒子也会改变效率。因此 ECRH 与 ECCD 的最优发射角未必相同，局部加热功率不能乘一个通用常数得到电流。Poli 等，§2.1–§2.2

吸收长度与功率分配

在电子回旋频段忽略离子响应，冷模型的 \(R=1-\omega_{pe}^2/[\omega(\omega-\Omega_e)]\)、\(L=1-\omega_{pe}^2/[\omega(\omega+\Omega_e)]\) 为无量纲介电分量。它们帮助定位传播区域，但冷模型的共振奇点不代表真实吸收可以无限大；热分布、有限波束及碰撞等物理会改变局部行为。冷介电分量定义

如果沿实际波路的强度吸收系数为 \(\alpha(s)\)，单位 \(\mathrm{m^{-1}}\)，定义光学厚 \(\tau=\int\alpha ds\)，则无其它损失的单程吸收份额为 \(1-e^{-\tau}\)。光学厚等于一时只吸收约 63.2%，不能称为全吸收。极化、谐波和温度改变的是这个积分中的物理耦合。若仍有透射功率，需要追踪后续反射与部件负荷；把多程吸收假定为百分之百会掩盖这些去向。该式是沿程功率方程 \(dP/ds=-\alpha P\) 的积分结果，不能替代计算热介电吸收系数本身。

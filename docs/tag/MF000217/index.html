磁坐标、方向与单位转换

MF000217草稿 · 待领域审核在连续正文中阅读

COCOS、磁通与 CGS/SI

同名径向坐标可能表示几何半径、归一化极向磁通或归一化环向磁通的平方根。例如 \(\psi_N=(\psi-\psi_a)/(\psi_b-\psi_a)\) 与 \(\rho_{\rm tor}=\sqrt{(\Phi-\Phi_a)/(\Phi_b-\Phi_a)}\) 定义不同，不能只改列名就互换；应由同一个平衡给出映射和体积 \(V\)。下标 \(a,b\) 分别表示磁轴与所选边界。

COCOS 原论文系统区分磁通是否含 \(2\pi\)、坐标定向和电流/磁场符号。它们会影响 \(q\)、\(F=RB_\phi\)、平行波数和同向/反向电流驱动。接口至少保存输入与输出 COCOS、磁通单位、磁轴/边界取值、环向角正向和电流定义，并对一个已知磁场方向的点做向量检查。

TGYRO 方程与单位表是实际例子：部分内部量使用 CGS，而本库工程预算使用 SI。由 \(1\,\mathrm{erg}=10^{-7}\) J、\(1\,\mathrm{cm^2}=10^{-4}\) m²、\(1\,\mathrm{cm^3}=10^{-6}\) m³，有

\[ 1\,\frac{\mathrm{erg}}{\mathrm{s\,cm^2}}=10^{-3}\,\mathrm{W\,m^{-2}},\qquad 1\,\frac{\mathrm{erg}}{\mathrm{s\,cm^3}}=0.1\,\mathrm{W\,m^{-3}}. \]

因此 \(2\times10^8\,\mathrm{erg\,s^{-1}\,cm^{-2}}\) 对应 \(0.20\,\mathrm{MW\,m^{-2}}\)。粒子能量、温度能量和归一化热通量也分别恢复单位；写在图上的“功率”必须明确是体积密度、面积通量、磁面输运通量还是已积分功率。

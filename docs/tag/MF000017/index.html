ICRF 功率链与电压电流应力

MF000017草稿 · 待领域审核在连续正文中阅读

典型能量路径为射频源和功率放大器、传输线及功率分配、匹配网络、真空馈通、天线电流带（strap）及邻近面对等离子体部件。假负载承担调试或特定网络中的反射功率，冷却和测量通道跨越整条链。实际位置、元件数量与连接随具体设计改变。ITER 的公开工程介绍可用于理解射频源、传输和匹配的接口；其中目标功率属于项目设计描述，作为设计目标记录。ITER，离子回旋系统工程链说明。

每个接口应标出参考平面、端口方向、频率范围、阻抗与功率定义。对单频峰值复振幅，令 \(\widetilde V=Z\widetilde I\)、\(Z=R+iX\)，平均有功功率是

\[ P=\frac12\operatorname{Re}(\widetilde V\widetilde I^*) =\frac12R|\widetilde I|^2 =R|I_{\mathrm{RMS}}|^2. \]

\(V\)、\(I\)、\(Z\) 的单位分别为 V、A、\(\Omega\)。若仪器或仿真采用 RMS 复幅值，就不应再乘 \(1/2\)。电抗与谐振储能会造成很大的局地电压、电流，即使净有功功率相同，馈通、接触件和电流带的电应力也可能明显不同。须保存端口功率之外的电压电流峰值及其空间位置。Ohio State Ximera，Power Transfer on a Transmission Line，峰值幅度下的入射、反射与净功率；MIT，Electromagnetic Fields and Energy，第 14.6 节，传输线与反射系数。

机械、电气和真空接口的耦合需要联合分析。馈通陶瓷承担电场和真空边界，接触电阻造成局部热源，热膨胀改变接触与几何，磁场及感应电流又施加机械载荷。材料、冷却通路、连接方式、温度测点和维护可达性应对应同一版图纸。法拉第屏蔽的作用依其几何及电磁耦合而定，剩余平行近场与鞘层驱动仍由场计算及测量确定。

复功率与电压电流应力

采用 RMS 复幅值，复功率为 \(\mathcal S=VI^*=|I|^2(R+iX)\)。其实部给有功功率 \(P=R|I|^2\)，虚部给无功功率 \(Q=X|I|^2\)；由此逐步得到 \(|I|=\sqrt{P/R}\)、\(|V|=\sqrt{P/R}\sqrt{R^2+X^2}\)。无功量描述周期内往返交换的能量，匹配网络通过电抗变换调节源端阻抗，局部大电流和大电压仍由各支路决定。

教学负载取 \(Z=3+4i\ \Omega\)、\(P=1\) MW，得到 \(I_{RMS}=577.35\) A、\(V_{RMS}=2.887\) kV、\(Q=1.333\) Mvar，视在功率为 1.667 MVA。峰值电压是 \(\sqrt2V_{RMS}=4.082\) kV。若在相同有功功率下电阻降为 1.5 Ω，电流增至 816.50 A；于是接触件的 \(I^2R_c\) 热源随电流平方变化。这样的接口表同时列有功、峰值电压、电流和相位，能将功率链的需求落实到馈通与连接件的热电计算。

推导起点与参考位置：MIT Electromagnetic Fields and Energy，§14.6，反射与阻抗变换；Monakhov 等 2013，JET external conjugate-T，§2–5。

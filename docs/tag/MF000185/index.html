Entry 6.9.3 · 专题

ICRH 快波、模转换与各组分吸收

MF000185草稿 · 待领域审核在连续正文中阅读

区分波支和能量接收者

计算应同时看快波能流、离子–离子混合层附近的转换、短波分支以及电子和各离子的吸收。基频离子吸收、二次谐波吸收、电子 Landau 阻尼和渡越时间磁泵浦对应不同响应；一条总沉积曲线会隐藏功率由哪类粒子接收。比较少数离子、二次谐波及三离子方案时，先保持总注入谱和参考功率一致，再改变组分与频率。

短波解析和等效功率汇

TORIC 的原始文献区分完整 FLR 波方程与 ORA：后者将转出的离子 Bernstein 波替换为等效功率汇，可减少解析短波所需的网格。若问题只要求转换份额和较粗沉积，ORA 可作为明确的降阶选项；若问题是短波传播距离、转换后再吸收位置或局部场峰，应保留相应波支并细化网格。冷张量加人为损耗层能让边界出射波离开计算域，但这一损耗不是热离子的物理吸收。两者应分别进入功率账本，避免把边界吸收当成芯部加热。

可将每种离子的直接 RF 吸收记为独立径向剖面，并同时保存天线输入、壁/边界出射和人为损耗项。随后 FP 计算给出的离子向电子碰撞传能再作为另一条通道输出，使“离子吸收占比”与“热电子得到的加热占比”有可追踪的区别。

来源：Brambilla 1999，§7–10 与 ORA 说明；Maquet 等 2023，§2–3 吸收边界。

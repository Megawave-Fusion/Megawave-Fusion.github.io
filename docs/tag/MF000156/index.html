Entry 1.8.3 · 专题

自举电流与双极输运

MF000156资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

径向压强和温度梯度，在俘获/通行粒子的轨道及碰撞动量交换作用下，可以产生磁面平均的平行自举电流。它无需变压器环电压直接驱动，但维持梯度仍需能量与粒子预算。“自举”因此不是没有能源消耗的独立电源，也不能把总自举份额高直接等同于电流剖面适合稳态运行。

简单香蕉区模型给出 \(j_{\rm bs}\) 与压强梯度、俘获比例和极向磁场的关系；多物种、碰撞性、三维磁场和强梯度会改变系数。实际应用应使用注明有效域的闭合，连同外部电流驱动一起演化 \(q\) 剖面。磁岛内压强趋平时，局部自举电流缺失可参与新经典撕裂模驱动；岛宽、种子扰动和射频电流沉积位置因此都很重要。Fitzpatrick：Neoclassical Tearing Modes，式 (14.198) 及其限制。

长期准中性要求径向电荷通量满足双极条件 \(\sum_s q_s\Gamma_s\simeq0\)，而不是要求每个物种都没有径向通量。在轴对称托卡马克的新经典近似中，动量守恒使主要径向通量具有内禀双极性；径向电场不能仅靠这一最低阶条件唯一确定。普通非轴对称仿星器的离子与电子通量对 \(E_r\) 的响应不同，双极条件往往参与确定 \(E_r\)，甚至可能有多个根。Fitzpatrick：Neoclassical Transport，式 (2.271) 附近的对比。

瞬态极化电流、外加非轴对称场及动量源会补充上述平衡。所谓电子根或离子根是特定输运问题的解，不能仅从电场正负判定全部稳定性；必须检查根的稳定性、剖面与诊断。

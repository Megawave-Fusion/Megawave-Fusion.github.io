平面波、符号约定与线性化

MF000112资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

本页使用 SI 制，物理扰动取复表示的实部：

\[ \delta\mathbf E(\mathbf r,t) =\operatorname{Re}\!\left[\widetilde{\mathbf E} e^{i(\mathbf k\cdot\mathbf r-\omega t)}\right], \qquad \partial_t\mapsto-i\omega, \qquad \nabla\mapsto i\mathbf k. \]

波数 \(k=2\pi/\lambda\) 的单位为 \(\mathrm{m^{-1}}\)，角频率 \(\omega=2\pi f\) 的单位为 \(\mathrm{s^{-1}}\)。如果取实 \(\mathbf k\) 和 \(\omega=\omega_r+i\gamma\)，振幅随 \(e^{\gamma t}\) 变化，因此 \(\gamma<0\) 才是时间阻尼。若改为实 \(\omega\)、沿 \(x\) 的复波数 \(k=k_r+ik_i\)，则 \(k_i>0\) 表示向 \(+x\) 的空间衰减。这两个问题的边界条件不同，不能直接把 \(\operatorname{Im}k\) 当成增长率。来源：Fitzpatrick，§5.2，式 (5.1)–(5.5)。

有磁场时取 \(\mathbf B_0=B_0\widehat{\mathbf z}\)、\(B_0>0\)，规定带符号回旋角频率与各组分等离子体角频率为

\[ \Omega_s=\frac{q_sB_0}{m_s},\qquad \omega_{ps}^2=\frac{n_{s0}q_s^2}{\epsilon_0m_s}. \]

电子的 \(q_e=-e\)、\(\Omega_e<0\)，正离子的 \(\Omega_i>0\)。除特别说明外，温度 \(T_s\) 用 K 表示，热能写成 \(k_BT_s\)；若输入以 eV 表示的数值 \(T_{s,\mathrm{eV}}\)，须先用 \(k_BT_s=T_{s,\mathrm{eV}}\times1.602176634\times10^{-19}\,\mathrm J\) 换算。本文的热速率定义为 \(v_{ts}=\sqrt{k_BT_s/m_s}\)，与另一些文献的 \(\sqrt{2k_BT_s/m_s}\) 相差 \(\sqrt2\)，代入 Maxwell 分布或 Landau 参数前必须换算。来源：Fitzpatrick，§5.3，式 (5.16)–(5.19)。

线性化指把 \(n_s=n_{s0}+n_{s1}\)、\(\mathbf v_s=\mathbf v_{s1}\) 等代入原方程，只保留一阶小量。例如 \(n_{s1}\mathbf E_1\)、\(\mathbf v_{s1}\times\mathbf B_1\) 是二阶项，但 \(\mathbf v_{s1}\times\mathbf B_0\) 是一阶项，必须保留。均匀无流背景使 Fourier 分量彼此独立；有梯度的装置中，局域结果还要求背景变化尺度显著长于局域波长。冷近似忽略的是相应响应中的压力与速度展宽效应，并非声称实际温度等于零；接近共振时，即使温度不高，热效应也可能成为主导修正。来源：Fitzpatrick，§5.1 Introduction。

阅读不同计算结果时，可以先做一个最小对照：检查电荷符号、磁场方向、时间指数以及温度定义是否相同，再比较色散曲线。一个程序返回负的电子回旋频率，另一个返回正的电子回旋频率幅值，两者未必矛盾；真正需要对照的是它们在运动方程与共振分母中怎样使用。类似地，复振幅乘上统一的常数相位不会改变物理偏振，但仅把一个分量共轭会改变旋转方向。波动问题中的许多“物理差异”首先是 convention 差异，只有完成这一层换算才能判断。

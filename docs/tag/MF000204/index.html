X-B 转换、倏逝层和有限 Larmor 半径

MF000204草稿 · 待领域审核在连续正文中阅读

热波支如何出现

直接 X-B 依赖快 X 波、截止及上杂共振构成的传播/倏逝结构；O-X-B 则先产生慢 X 支，再在上杂附近连接 EBW。两条路线都需解析转换区，但边界条件和穿过的倏逝层不同。EBW 的垂直波长可达到电子回旋半径量级，FLR 响应是支撑这一热波支的组成部分。单纯冷张量在上杂层加数值阻尼，不能据此证明功率已变成可传播 EBW。

冷全波与动理学全波的分工

冷全波常用于 O-X 波形、束效应和转换窗口；X-B 与热波支需热介电响应、合适转换模型或动理学方法。Khan 等以 TASK/W1 一维有限元和积分介电张量同时处理 FLR、O-X-B 和谐波吸收，提供了可检查的一维热全波基准。装置问题可先用它检验平板转换物理，再用实际几何处理束传播。网格必须同时覆盖真空波长和最短热波长，且随网格/损耗参数变化核对反射、转换与吸收，避免把正则化损耗误认为转换效率。

在无真实耗散的转换基准中，应以入射、反射和各传播分支出射的能流检查平衡。若在上杂附近人为加入碰撞以消除奇点，要把这部分耗散单列，并扫描碰撞参数，判断所得结果是传播分支转换还是局部数值功率汇。

来源：Khan 等 2016，原期刊摘要；相关热波原理。

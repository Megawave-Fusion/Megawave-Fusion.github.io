Entry 5.1.1 · 专题

诊断方法

MF000059资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

密度：干涉测到的是线积分

在探测频率远高于电子等离子体频率、碰撞和磁化修正可忽略、光路近似不变时，折射率展开给出相对真空的相位差

\[ \Delta\phi\simeq-r_e\lambda\int n_e(l)\,dl,\qquad r_e=\frac{e^2}{4\pi\epsilon_0m_ec^2}. \]

这是单程表达；往返探测应沿实际总光路积分。这里采用“等离子体光路相位减真空光路相位”的约定；电子使折射率低于一，故相位差为负。仪器的混频约定可能反号。积分单位是 \(\mathrm{m^{-2}}\)，乘以 \(r_e\lambda\) 后为无量纲相位。只有除以已知弦长，才得到该弦的平均密度；不能直接称为中心密度。多弦测量结合轴对称假设可作 Abel 反演，非轴对称情形需要更多视角或其他约束。条纹跳变、折射偏转、机械振动与中性粒子折射率均可能改变结果。依据 IPP 等离子体干涉实验讲义 的折射率、线积分反演和 Refraction 部分；本页公式是该高频极限的代数展开。

温度：汤姆逊散射、光谱与 ECE

非集体 Thomson scattering 的频谱形状反映散射波矢方向上的电子速度分布；在所用热分布模型成立时拟合得到 \(T_e\)，绝对散射强度结合激光能量、收集立体角和谱响应标定给出 \(n_e\)。它是有限散射体积和激光脉冲时间内的测量，不是数学意义上的一点。背景光、杂散激光和通道响应必须进入拟合，拟合残差过大时应检查非热分布或标定问题。集体散射可能包含离子特征，不能沿用非集体谱公式。参见 PPPL Diallo 2018 课程，PDF 第 23–34、38–40 页。

光谱诊断首先辨认谱线及其产生机制，再讨论温度或流速。沿视线的 Doppler 位移用于约束发射粒子的速度；线宽还包含仪器、自然、Stark 等贡献。把所有展宽都归为热运动会高估温度。主动电荷交换谱的局域性来自束与视线交叠，仍需扣除被动背景、考虑原子过程和几何。光强增加也可能来自密度、杂质含量或激发率变化，不单独证明温度升高。氦还可能出现沿磁场运动后产生的非局域 plume 发射，不能认为所有信号都局限在束交叠处。见 IPP 2014 氦输运与电荷交换谱说明正文；这里只引用其诊断限制，不移用实验数值。

ECE 是电子回旋辐射。只有热电子分布、足够光学厚度、合适传播模式和空间定位等条件满足时，亮温才能近似对应局域电子温度。光学薄情形同时依赖密度、路径与温度；快电子可能贡献很强的非热辐射。因此 ECE 与 Thomson 不一致时，应先比较测量体积、时刻、标定与分布假设。依据 Liu 等，2016 ECE 报告，第 7–9 页热平衡和光学厚度、第 15–18 页非热贡献；不引用其简化模型作为普遍定量定律。

磁场、中子、辐射和壁面热负荷

磁感应线圈测 \(V=-N\,d\Phi_B/dt\)，积分得到的是磁通变化；初值、零点漂移、线圈方向和有效面积需要另行确定。长脉冲中微小直流偏置会积累为明显误差。磁通环、局部探针和等离子体电流信号共同约束平衡重建，但有限外部数据并不唯一确定内部电流和压力剖面，还需平衡方程、边界与内部诊断。参见 MIT 22.67J Magnetics I 课程文字稿，开头的 Faraday 定律、积分与偏置讨论。

中子计数转为总中子产额需要效率、能量响应、立体角、散射和死时间修正；相机和谱仪还提供空间或能量信息。反应率取决于参与反应的分布，束靶反应和热反应不能仅凭总计数分开。辐射计接收沿视线的辐射，少量弦的层析结果受几何与正则化影响；彩图的像素数不等于独立空间分辨率。上述系统的用途见 ITER 诊断系统的 Neutron diagnostics 与 Bolometric systems 段。

红外相机测的是波段辐亮度，经过透过率、发射率和反射背景修正才成为表面温度；热流密度还要用材料热物性和导热模型反演。薄沉积层、表面改性和有限厚度会破坏简单半无限体近似。热电偶能提供补充约束，但响应速度和埋深与红外不同。历史案例 NSTX 红外测量报告 的 Infrared measurements 与发射率讨论说明了这些限制，不能把其材料条件直接移用于另一装置。

LH 边缘损失与硬 X 射线对照

MF000202草稿 · 待领域审核在连续正文中阅读

芯部吸收之外的功率去向

密度升高后，芯部驱动电流下降不一定能由可达性或衍射单独解释。应显式区分进入芯部的波功率、SOL 中碰撞耗散、返回边界的功率，以及快电子径向输运或损失。Yang 等的 EAST 研究同时检查实际 SOL 几何/剖面和快电子扩散，说明这些环节会改变沉积与电流的联合解释；它们需要各自输入，不能由一个总效率吸收掉。

将电子分布变成诊断信号

模型验证可先比天线反射和耦合功率，再将 FP 分布经制动辐射截面、探测视线和仪器响应计算成硬 X 射线能谱与空间信号，最后与电流和磁约束联合判断。总电流相符可能仍对应错误尾电子能谱，硬 X 射线相符也可能受径向输运与剖面误差补偿。建议同时扫描边缘密度/温度、发射谱、有效电荷与快电子输运，在各观测中保留同一组参数。对于调制实验，还应比较时间响应，区分 LH 波传播时间、快电子建立时间与电流扩散时间。

前向诊断需保留视线积分和能道响应：不同俯仰角的电子对探测器的辐射贡献不同，某一条视线的硬 X 射线幅度不能直接当作局部尾电子密度。多个视线和能道共同约束分布，才有助于区分能谱变化与径向再分布。

来源：Yang 等 2014，SOL、径向输运及欧姆电流摘要；CQL3D 官方说明及 Results/文献入口。

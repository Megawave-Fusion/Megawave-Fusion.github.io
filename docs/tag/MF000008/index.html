Entry 2.1.1 · 专题

托卡马克

MF000008资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

螺旋磁场与安全因子

托卡马克以近似轴对称的环形磁面约束等离子体。外部环向场线圈提供主要环向磁场，等离子体环向电流产生极向场；外部极向场线圈同时参与位置、形状和平衡控制。两种场叠加使磁力线绕着磁面螺旋前进。只有环向场时，曲率和梯度漂移不能充分抵消，因此“把磁场弯成圆环”本身不够。IPP《Tokamak》，磁场组成与电流驱动段。

安全因子 \(q\) 表示磁力线绕极向一周时的环向圈数。在大环径比、近圆截面且局部磁场近似成立时，

\[ q(r)\simeq\frac{rB_\phi}{R_0B_\theta(r)},\qquad B_\theta(r)\simeq\frac{\mu_0I_p(r)}{2\pi r}. \]

\(r,R_0\) 为小半径与主半径，单位 m；磁场单位 T；\(I_p(r)\) 是所包围的电流，单位 A。式子来自磁力线几何和安培环路定律，不能原样用于强整形、球形托卡马克的精确平衡。举一个解析教学例：取 \(r=0.5\,\mathrm m,R_0=2\,\mathrm m,B_\phi=3\,\mathrm T,I_p(r)=0.5\,\mathrm{MA}\)，得到 \(B_\theta=0.20\,\mathrm T,q\simeq3.75\)。这里的 \(q\) 不是设备安全系数，更不意味着“超过某数就没有不稳定性”。撕裂模对 \(q=m/n\) 的有理磁面敏感，判断稳定性还要看电流、压力、剪切、旋转与壁面条件。Fitzpatrick，撕裂模讲义，式 (4.35)–(4.40)。

电流维持、稳态和破裂

变压器感应电流需要磁通变化，可用的磁通摆幅有限，因此纯感应驱动通常是脉冲运行。非感应方案由外加波或束流驱动电流，并利用压力梯度产生的自举电流；稳态要求电流剖面、热量、密度、杂质和壁温都能维持。超导线圈使长时磁场成为可能，但不会自动解决等离子体电流维持及排热。IPP《Tokamak》，末两段。

从磁能看，变化的电流不能瞬间消失：简化电路满足 \(V=L\,dI/dt+RI\)。托卡马克破裂可能伴随快速热能损失、随后电流下降、电磁载荷及逃逸电子。热能 \(W\) 在较短时间 \(\Delta t\) 释放时，平均释放功率约为 \(W/\Delta t\)；落点面积和辐射分配又决定局部热流，不能只按总能量评价损伤。ITER 的破裂缓解系统是面向未来运行的工程设计，不能写成已经在 ITER 等离子体上完成验证。ITER《Disruption mitigation》，破裂后果与系统方案。

球形托卡马克通过较小环径比 \(A=R_0/a\) 改变平衡和稳定性条件，常研究较高的归一化压力，但中央柱、屏蔽和维护空间也更紧。常规与球形装置比较时，必须同时报告压力定义、磁场位置、等离子体体积及加热功率，而不能只比较峰值温度。

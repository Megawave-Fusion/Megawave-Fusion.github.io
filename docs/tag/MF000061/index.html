Entry 5.1.3 · 专题

实时控制与联锁接口

MF000061资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

闭环需要整个信号链的时间预算

诊断采样、滤波、反演、网络传输、控制计算和执行器响应都贡献延迟。若简化为纯延迟 \(\tau\)，频率 \(f\) 处新增相位为 \(-2\pi f\tau\)；这是对延迟算子 \(e^{-s\tau}\) 的直接计算，说明提高采样率并不能消除慢执行器。反馈设计还要检查带宽、饱和、速率限制、噪声放大和积分饱和。密度、位置、电流和加热分配存在耦合，多回路共享执行器时需要明确优先级和可用功率约束。

信号接口至少包含单位、坐标约定、时间戳、有效期、有效性标志与配置版本。迟到或失效的估计不能继续当作新测量。允许怎样降级、保持多久、何时退出当前状态，需要由装置需求定义并用仿真、回放和受控试验验证。

正常控制、机器保护与安全系统

正常控制追踪目标轨迹；机器保护限制设备损伤；人员和核安全系统处理另一组安全需求。这些功能的权限、独立性和验证依据必须分别说明。ITER 的官方架构明确将机器保护和安全系统与 CODAC 解耦并独立动作，见 CODAC Architecture 正文。不能把普通监控画面的报警灯等同于保护链，也不能把一次正常放电当作故障条件测试。联锁试验应记录输入条件、触发动作、响应时间、复位条件及测量证据；这里不设任何通用阈值。

圆偏振、离子旋向与基频耦合

MF000137草稿 · 待领域审核在连续正文中阅读

“左旋”“右旋”在不同文献中可能按观察方向命名，最稳妥的做法是同时给出时间因子、磁场方向和旋转矢量。在本文约定下，正离子的自由回旋满足 \(v_x+i v_y\propto e^{-i\Omega_i t}\)。定义单位归一圆基

\[ \mathbf e_{\mathrm{ion}}=\frac{\hat{\mathbf x}-i\hat{\mathbf y}}{\sqrt2},\qquad \mathbf e_{\mathrm{opp}}=\frac{\hat{\mathbf x}+i\hat{\mathbf y}}{\sqrt2}, \]
\[ \widetilde E_{\mathrm{ion}}= \frac{\widetilde E_x+i\widetilde E_y}{\sqrt2},\qquad \widetilde E_{\mathrm{opp}}= \frac{\widetilde E_x-i\widetilde E_y}{\sqrt2}. \]

于是 \(|\widetilde E_x|^2+|\widetilde E_y|^2=|\widetilde E_{\mathrm{ion}}|^2+|\widetilde E_{\mathrm{opp}}|^2\)，同向基的介电本征值为 \(L=S-D\)。有些文献把旋转分量定义为除以 \(2\)，只要能量公式同步调整即可；比较功率时应将归一化统一。

在上一条忽略平行电场的近似下，由 \(A\widetilde E_x-iD\widetilde E_y=0\) 得

\[ \left|\frac{\widetilde E_{\mathrm{ion}}}{\widetilde E_{\mathrm{opp}}}\right|^2 =\left|\frac{R-N_\parallel^2}{L-N_\parallel^2}\right|^2. \]

对于只有一种主要离子的理想冷模型，接近其基频时 \(L\) 的极点可使快波的离子同向分量相对于反向分量受到抑制。这解释了一个关键现象：回旋共振与自洽快波的旋向电场共同控制耦合。因此单组分热离子的快波基频加热往往较弱，多离子组分和谐波方案可以改变情况。

这里的波场由色散自洽决定，前面的单粒子解则采用规定电场。有限温度、传播边界和阻尼决定实际场与功率分配；对少数离子也采用同样的热响应处理其冷回旋极点。

来源：Fitzpatrick，§5.5 Wave Polarization，式 5.56–5.60；§5.9 Parallel Wave Propagation；Fukuyama 2025，PDF 第 24 页。

从 Jones 分量算离子同向场份额

沿用 \(e^{-i\omega t}\) 与本页圆基，\(E_{ion}=(E_x+iE_y)/\sqrt2\)、\(E_{opp}=(E_x-iE_y)/\sqrt2\)。令 \(E_x=a\)、\(E_y=-ib\)，直接展开得两个模平方分别为 \((a+b)^2/2\) 与 \((a-b)^2/2\)，相加为 \(a^2+b^2\)。若相位从 \(-\pi/2\) 偏离 \(\delta\)，同向份额成为 \(1/2+ab\cos\delta/(a^2+b^2)\)。

取峰值复幅 \(E_x=100\) V/m、\(E_y=-50i\) V/m，同向和反向圆分量幅值分别为 106.066 与 35.355 V/m，同向场模平方份额为 90%。相位偏离 5° 后，该份额为 89.848%。这只是给定位置的偏振分解；吸收计算把相应分量与组分响应及速度空间积分相乘。将探头或全波输出转换为统一圆基后，可以逐点检查极化变化，同时用两分量平方和守恒发现归一化错误。

推导起点与参考位置：Fitzpatrick，Cold-Plasma Dielectric Permittivity，式 (5.31)–(5.39)；Fitzpatrick，Waves in Magnetized Plasmas，式 (7.53)–(7.78)。

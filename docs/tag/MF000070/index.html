Entry 7.1.4 · 专题

燃料、注入与循环

MF000070资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

D–T 燃料循环包括供给等离子体、回收未反应燃料、分离氦与杂质、同位素处理、再供给和库存测量。气体注入首先影响边缘中性粒子；丸注入通过固态燃料进入更深区域后消融，有助于改变粒子沉积剖面，但仍取决于丸与等离子体条件。核心燃料密度不能简单由阀门流量等同得到，因为壁面再循环、抽气与粒子输运同时存在。ITER《Fuelling》，燃料注入与回收系统。

燃烧消耗与循环流量

每次 D–T 反应消耗一个氚核。LLNL 诊断说明，One Key Measurement 段给出每次反应约 17.6 MeV 总能量及以中子数推断反应次数的原理。把每次反应能取为 \(E_{DT}\simeq17.6\,\mathrm{MeV}=2.82\times10^{-12}\,\mathrm J\)，仅由能量与粒子守恒可得

\[ \dot N_{\rm burn}=\frac{P_{\rm fusion}}{E_{DT}},\qquad \dot m_T=m_T\dot N_{\rm burn}. \]

这是聚变热功率，不是发电功率。假想连续 1 GW D–T 聚变热功率对应约 \(3.55\times10^{20}\) 次反应/s，按 \(m_T\simeq5.01\times10^{-27}\,\mathrm{kg}\) 估算，氚燃烧约 \(1.78\,\mathrm{mg\,s^{-1}}\)，365 天满功率约 56 kg。若可用率较低，年度燃烧量按实际聚变热功率时序积分；这个例子不包含循环库存，也不是某装置的供料规范。

燃烧比例 \(f_b\) 若按氚核数定义为所注入氚中被反应消耗的比例，则理想稳态氚注入率尺度为 \(\dot N_{T,\rm inj}=\dot N_{\rm burn}/f_b\)；这里每次 D–T 反应消耗一个氚核，所以氚燃烧率等于上式的反应次数率。若改用 D 与 T 的总核数，分子与分母都须采用同一计数口径。未燃部分回收再循环，所以低单程燃烧比例显著增大处理流量，却不等于同样倍数的新氚年需求。必须严格区分注入、循环、外部补给与实际燃烧四种流量。

增殖、延迟与库存

常见增殖反应之一是 \({}^{6}\mathrm{Li}+n\rightarrow{}^{4}\mathrm{He}+T\)。增殖比 TBR 定义为生成氚核数与消耗氚核数之比，但“生成”还需经提取和回收才成为可用燃料。损失、处理延迟、备用库存和新机启动要求，使燃料自持不能只靠一句 TBR 大于一判定；没有适用于一切堆型的统一余量。ITER 测试包层模块旨在检验相关技术，不是已经完成全尺寸商业燃料闭环的证明。ITER《Tritium breeding》，TBM 试验目标与后续研究边界。

对包含所指定回收与储存系统的库存边界，质量守恒可写成

\[ \frac{dM_T}{dt}=\dot M_{\rm bred,rec}+\dot M_{\rm external} -\dot M_{\rm burn}-\dot M_{\rm loss}-\lambda_T M_T. \]

边界内部的搬运不应重复记为净收入。\(\lambda_T=\ln2/t_{1/2}\)，NIST 2000 年评估推荐半衰期 \(4500\pm8\) 天，约 12.32 年；按这一值，隔离库存一年衰变约 5.5%。此例只说明库存随时间变化，不能替代含氚系统的测量、许可或操作要求。Lucas 与 Unterweger，NIST，2000，摘要与推荐值。材料滞留与渗透会使测量边界复杂化，见等离子体与材料相互作用。

软件分工与建模步骤

MF000238草稿 · 待领域审核在连续正文中阅读

每次增加一种复杂性

工具或模型 用于哪一步 必须另给的输入/边界
本库解析电流谱与给定 Z 网络 检查幅相、功率波和归一化 规定电流或给定阻抗，不从 CAD 预测负载
ANTITER 平板/谱模型的负载、相位及吸收边界基准 具体版本的几何与等离子体近似
TOPICA 三维导体与谱等离子体响应连接、S/Z 及表面电流 常用分层等离子体响应；不是任意三维全局热等离子体
RAPLICASOL / COMSOL 三维天线近场、冷等离子体及 PML 冷张量、密度剖面、磁场方向与 PML 实现
HFSS 的论文实现 复杂导体、等效电导张量与 ABL 论文方法的实现；默认材料库不等于完整等离子体模型
WEST IC Antenna / scikit-rf 把电磁多端口接入电容、馈线及有源匹配 共同端口、频率、单位、参考面和终端

方法依据：TOPICA 原论文、HFSS 模型与 ANTITER 基准、WEST COMSOL 接口。通用电磁软件需要按这些方法建立等离子体响应；软件名称本身不能说明模型包含哪些物理。

三维初始模型怎样搭建

建模步骤 保留的结构与设置 对应的物理问题
几何与材料 画带、馈入、短路和回流腔，先用 PEC 与真空 电流从哪里进入、在哪里回流，哪些尺寸控制电感与电容？
建端口 在均匀同轴段选 TEM 模；固定参考阻抗、方向与参考面 馈电电压、电流和相位定义在哪里，端口间怎样互耦？
加等离子体 从均匀冷张量扩展到密度剖面，并给定磁场方向 波以什么极化传播，天线与截止层间怎样耦合？
接馈电网络 加入电容、馈线与终端，指定各路幅相 馈电相位如何变成带电流，负载变化怎样影响匹配？
恢复细节 加屏、曲率、圆角和有限电导 屏条与框架怎样改变平行近场，哪里产生导体损耗？

从真空结构到等离子体负载逐层增加复杂性，能把几何影响、馈电变化和等离子体响应分开解释。比较两种模型时，先统一参考面、净接受功率、密度剖面和实际带电流，再比较阻抗、发射谱及指定位置的近场。得到一致的天线输入后，继续阅读ICRH 吸收与分布模型。

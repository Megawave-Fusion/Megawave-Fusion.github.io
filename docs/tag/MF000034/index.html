Entry 3.5.1 · 专题

原理与适用条件

MF000034资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

频率范围与朗道共振

在通常的磁化电子、较弱磁化离子条件下，低杂频段位于离子和电子回旋频率之间。单一离子组分、冷等离子体近似下，低杂共振可估为

\[ \omega_{LH}^2\simeq\Omega_i^2+ \frac{\omega_{pi}^2}{1+\omega_{pe}^2/\Omega_e^2}. \]

这里 \(\Omega_s=|q_s|B/m_s\)、\(\omega_{ps}^2=n_sq_s^2/(\epsilon_0m_s)\)，均为角频率，单位 \(\mathrm{rad\,s^{-1}}\)。加热源工作在这一频段，并不意味着每个波包必须落在局部 \(\omega=\omega_{LH}\) 共振层。LHCD 的主要电子吸收机制是平行电场的朗道作用：\(\omega-k_\parallel v_\parallel=0\)。定义 \(N_\parallel=ck_\parallel/\omega\) 后，共振电子满足 \(v_\parallel=c/N_\parallel\)。Wallace 等，FNSF 原论文 §2.1

发射谱向一个平行方向偏置，波对相应电子群进行准线性扩散，碰撞和粒子输运则不断松弛该分布，最终形成携带电流的快电子尾。若正负方向对称，吸收可以很强而净电流很小。电流方向按电子负电荷定义，必须说明是电子流向还是常规电流方向。Wallace 等，CFETR 研究 §1–§2

可达性与吸收之间的窗口

一个常用的冷、局部、单离子近似可达性条件是

\[ |N_\parallel|\gtrsim N_{acc}= \frac{\omega_{pe}}{\Omega_e} +\sqrt{1+\frac{\omega_{pe}^2}{\Omega_e^2}-\frac{\omega_{pi}^2}{\omega^2}}. \]

它表示慢波分支在传播途中避免与快波分支合并而失去可达性的一项必要约束；根号内量、频率区间和局部参数需满足该推导的适用条件。它不保证边缘耦合良好，也不替代全路径传播计算。密度升高增加 \(\omega_{pe}\)，较强磁场增大 \(\Omega_e\)；所以高场侧发射可能扩大允许的传播窗口，但不能简单宣称“高场侧永远穿透到中心”。CFETR 原论文，式 (2) 与 §2

较低 \(|N_\parallel|\) 对应较快、碰撞较少的共振电子，通常有利于电流效率；过低会遇到可达性障碍或缺少足够共振电子。较高 \(|N_\parallel|\) 更容易在较冷区域吸收，却可能在外层提前沉积。常见的 \(I/P\) 随 \(N_\parallel^{-2}\) 改善只是高能碰撞模型的尺度趋势，不能跨越可达性、捕获粒子或强准线性条件外推。FNSF 原论文，§2.1

发射谱不等于吸收谱

波沿环形磁场传播时，局部 \(k_\parallel\) 由波矢与磁场的投影决定；极向折射、磁剪切和几何变化会使 \(N_\parallel\) 上移或下移。轴对称性约束环向模数，却不使整个 \(N_\parallel\) 沿射线恒定。边缘密度涨落还可能散射波束。因此模型必须报告吸收处的谱和沉积，而不能只用天线标称谱解释电流效率。CFETR 原论文，式 (3)–(4) 及 §4

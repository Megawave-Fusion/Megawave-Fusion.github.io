Entry 6.9.3 · 专题

双电流带的间距、相位与发射谱

MF000231草稿 · 待领域审核在连续正文中阅读

电流谱先做解析检查

设两条宽 \(w\) 的均匀薄带沿 \(z\) 相隔 \(d\)，总带电流为 \(I\) 与 \(I e^{i\Delta\phi}\)。每带面电流密度为 \(K_y=I_p/w\)（A/m），带宽以外为零。对空间变换 \(\widetilde J(k_z)=\int K_y(z)e^{-ik_zz}dz\)，归一化电流谱为

\[ \frac{|\widetilde J(k_z)|^2}{|I|^2} =\operatorname{sinc}^2\!\left(\frac{k_zw}{2}\right) \left|1+e^{i(\Delta\phi-k_zd)}\right|^2, \quad \operatorname{sinc}u=\frac{\sin u}{u}. \]

同相在 \(k_z=0\) 相加，反相在该处相消；\(\Delta\phi=\pm\pi/2\) 使谱偏向不同方向。这个量是规定电流的 Fourier 谱，功率谱还要用等离子体响应和 Poynting 通量计算。局部 \(k_\parallel\) 则由波矢对总磁场投影得到。TWA 论文 §4–5明确区分电流设计与实际开口功率谱。

教学取 \(w=0.06\) m、\(d=0.18\) m，反相阵列因子的第一对峰在 \(k_z=\pm\pi/d=\pm17.45\) m⁻¹；乘单带包络后，该点谱值为 3.6476，完整谱峰位置略变。保持每带电流相同是谱检验；比较实际效率时应重归一到相同接受功率，并从含互耦的网络求实际带电流。

Entry 10.1.1 · 专题

学习路径

MF000080资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

从基本尺度走向一个完整问题

先学 等离子体基本概念，能解释温度、密度、德拜屏蔽、准中性以及各条件何时失效；再读 单粒子运动，区分回旋、漂移、导心与约束。随后进入 动理学与碰撞，理解分布函数、矩、弛豫和非热粒子，避免把所有粒子群都用一个温度代表。

流体与磁流体力学建立宏观平衡和稳定性的语言，等离子体波连接色散、共振和波粒交换。顺序依据概念依赖安排，不要求把整本教材读完才进入具体问题。基础阶段可沿 MIT 22.611J 讲义目录的单粒子、碰撞、流体及波动章节推进；本次核对课程目录及主题对应，不声称重审了全部讲义推导。

把专题读成一条证据链

选择 ICRH、ECRH、NBI 或 LHCD 后，依次回答：能量从哪里进入、怎样到达等离子体、哪些粒子吸收、如何热化或驱动电流、哪些诊断能检验、哪些损失仍未解释。这样可以把物理机制与电源、传输、壁面及控制接口连接起来。

每轮阅读产出一页说明：问题和适用条件、关键公式及符号、可观察量、来源位置、一个独立复算和未解决项。随后用 诊断控制、仿真计算 与 实验运行检查模型和证据是否真正闭合。能复述摘要，不等于能复现结论。

中性粒子、回收与脱靶

MF000161资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

到达壁面的粒子可被反射、吸附或以原子/分子形式重新进入等离子体；这些回收粒子再经历电离、激发、电荷交换与分子反应。回收系数需说明计量的是原子核数、分子数还是粒子通量。电荷交换可以把离子的能量与动量转移给中性粒子，而光辐射、电离和复合改变功率及粒子预算。

脱靶通常指靶端等离子体从高温、强附着状态进入冷却并降低靶负荷的运行状态。需要同时研究功率、动量和粒子平衡：仅看到靶温度下降，不能证明离子通量已经出现 rollover（随上游条件变化先增后降），也不能证明抽排和核心性能满足要求。

可用控制体积写 \(\dot N_{\rm target}=\dot N_{\rm upstream}+\dot N_{\rm ion}-\dot N_{\rm rec}-dN/dt\)，这里 \(N\) 是控制体积内的等离子体离子库存，target/upstream 是离子流率，ion/rec 分别为电离生成及复合移除离子的速率；各项按离子所含原子核数统一计量，旁向通量存在时还应补项。若改统计包含中性态的全部原子核库存，电离/复合只在电荷态之间转移，不能作为总核数源汇。靶离子流减少可能来自电离源功率不足、净复合、动量损失改变流动等共同作用，不宜把所有脱靶归因于单一复合过程。Dudson 等：SD1D 的粒子、能量与动量损失研究，作者摘要。

分子辅助复合/解离在部分低温高密度条件中可成为重要通道。MAST-U Super-X 的原始研究结合谱学与功率/粒子预算讨论了这些过程；其具体结论必须保留装置、气体和模型条件，不可直接给所有偏滤器套同一阈值。Verhaegh 等：MAST-U 等离子体—原子—分子相互作用研究，作者摘要。

稳定排热还要求辐射区位置、杂质穿透、泵速与核心稀释可控。诊断上应把光谱、红外靶热流、探针、密度和辐射测量合并核算；一个亮度图像不足以独立确定电子温度或全部损失。

Entry 1.1.2 · 专题

约束与性能指标

MF000002资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

磁约束通过粒子轨道和集体平衡限制跨场损失；惯性约束在燃料迅速解体前利用短暂高密度产生足够反应；磁惯性路线则在压缩与磁化之间组合条件。三者需要不同的损失模型，不能直接按“放电时长”排序性能。装置路线进一步说明磁拓扑、驱动和工程代价。

能量约束时间常定义为 \(\tau_E=W_{\rm th}/P_{\rm loss}\)。若储能正在变化，\(P_{\rm loss}=P_{\rm heat}-dW_{\rm th}/dt\)；还需说明是否已经包含辐射。粒子约束、快粒子慢化和放电脉宽各描述不同过程。三乘积 \(nT\tau_E\) 引用时必须给出密度物种、中心/平均温度、温度单位及是否同一时刻实现，不能把不同放电的最好数值相乘。Wurzel 与 Hsu：Lawson 综述，§IV 的实验比较方法。

若用 \(Q_p=P_{\rm fus}/P_{\rm ext}\)，须明确 \(P_{\rm ext}\) 是被吸收功率、注入边界功率，还是其他定义。电网消耗还涉及源效率与辅机；工程净电又涉及热循环。所谓“盈亏平衡”必须带上系统边界。温度高、脉冲长、增益高和净供电分别提供不同证据，均不应单独代替完整评价。

Entry 1.1.4 · 专题

等离子体波与波粒相互作用

MF000004资料与公式已复核（模型辅助） · 待专家审核在连续正文中阅读

线性波分析从规定的平衡分布与 Fourier 约定出发，求介电响应、极化和色散。冷等离子体模型能说明许多截止与共振的位置，但没有速度分布的细节，不能单独给出实际热吸收和非热尾部。均匀介质的局域传播条件也不等于天线已经能把功率耦合进入目标区域。

Landau 共振比较波相速度与粒子的平行速度；回旋共振还涉及粒子回旋相位，典型形式为 \(\omega-k_\parallel v_\parallel-l\Omega_s=0\)。本式中 \(\Omega_s=q_sB/m_s\) 为带符号角频率，\(l\) 为整数；采用正频率约定的系统页面会另行说明极化与谐波符号。共振条件只是相互作用条件，净吸收或增长还由分布梯度、极化和阻尼决定。

等离子体波将 Langmuir、离子声、O/X、whistler 与 MHD 分支分开，并核对冷介电、功率与阻尼。辅助加热再连接波传播、沉积、快粒子慢化和电流驱动。一个完整加热结论应说明发射功率、耦合功率、吸收对象与位置，而不只列发生器频率。

弹跳平均 Fokker–Planck 与电流

MF000182草稿 · 待领域审核在连续正文中阅读

CQL3D 与 LUKE 的输入输出

软件 物理层级 主要输出 模型边界与比较重点
CQL3D 相对论、弹跳平均的碰撞/准线性 FP；常用两动量维加一径向维 非热电子/离子分布、加热、电流驱动和相关诊断量 名称中的 3D 不表示三维空间全轨道；RF 扩散和几何须由对应模型或上游求解器提供
LUKE 所引教程为相对论、弹跳平均电子 FP，一空间维加两动量维 电子分布、电流驱动与相关响应 核对背景、碰撞线性化、波输入、电场和输运；该教程基于 MATLAB

强非热情形中，场给出准线性扩散，分布改变吸收和介电响应，二者可能需要迭代。比较功率时统一天线/入射面、反射、金属/介质损耗、电子/离子吸收和出域功率。频域复场采用峰值幅度时，周期平均功率密度（W/m³）常写为 \(\tfrac12\operatorname{Re}(\mathbf J\cdot\mathbf E^*)\)；采用 RMS 幅度时因子相应改变，必须跟随软件约定，例如 HFSS 的相量说明。RF—FP 功率矩的核对方法见多物理耦合。

本轮离子回旋加热补充

离子回旋加热（ICRH / ICRF）共 17 条、约 9000 汉字，另含公式、算例和引用。理论部分覆盖有限时间单粒子共振、Doppler 位移与共振层、冷介电和快波极化、少数离子、二次谐波、模转换、三离子方案；工程部分覆盖分布演化、碰撞传能、设备接口、射频功率、RF 鞘层、控制保护及验收。

两名编写代理分别完成理论和工程稿；另一名未参与编写的代理逐条交叉审读，主代理整合后再次核对。复核明确了圆偏振归一化、正负回旋频率、温度能量、分布函数归一化、峰值与 RMS 功率系数，以及波吸收与内部碰撞传能的区别。未发现尚未处理的实质问题，但这仍是模型辅助复核，领域专家审核待完成。

本轮新增 25 项可复现的独立数值检查：以 Cartesian Lorentz 轨道积分核对五种裸核回旋频率；检查 Doppler 位移、1/R 磁场共振位置；比较共振、失谐、反旋与线偏振的解析解和 RK4 数值解，检查步长收敛与电场做功；以实波形积分核对峰值/RMS、入射反射预算及驻波比。另用数值积分交叉检查张量功率、冷波极化和准线性扩散能量矩。25 项均通过，限定范围和结果数值保存在结构化记录的 icrh_update 中。

正文含 27 个不同的外部来源链接，新增来源索引记录 18 条；已有来源继续沿用原记录。本轮读取 ITER 2025 学校讲义、作者公开论文及官方机构页面，对公式密集的关键 PDF 页进行了视觉核对。部分文献仅使用作者摘要，其获取范围单独记录。历史 IPP 课程链接本轮返回 HTTP 401，没有取得正文，因此明确排除在新增结论的依据之外；未把链接返回成功等同于技术审核通过。

ICRH 连续正文的 144 个公式节点在浏览器正常渲染；更新后全站 922 个去重公式通过 MathJax 转换。桌面与 390 像素窄屏检查覆盖内容和目录，章节链接、工具链接统一放大到 17px，移动导航为 16px；公式过长时保留局部横向滚动。检查没有运行真实装置的全波/FP 耦合，也没有代替设备测试和验收。

第一批公式与算例检查

可复现脚本完成 43 项独立基准检查，包括：

  • eV–K 换算、Debye 长度与球内粒子数、电子/氘频率、热速度、惯性长度、回旋半径与 beta。
  • 给定密度、温度和 Coulomb 对数下的电子—离子参考频率及自由程。
  • 数值积分高斯分布的归一化、平均流速、压力、奇热流矩和动能分解。
  • 直接积分正、负电荷的 Lorentz 轨道，检查周期平均 E×B 漂移。
  • 磁镜反射边界、从粒子响应验证冷介电圆偏振本征向量、MHD 快慢根的极限与乘积。
  • 用解析构造解检查 Grad–Shafranov 算符符号，用独立向量运算检查机械功/焦耳热，用正弦扩散解检查磁能损失与焦耳热一致。

这些检查覆盖上述明确的教学算例与恒等式；没有声称运行真实装置的全波、平衡稳定性或输运模拟。复核原始记录和输出数值见 结构化核验记录。

已处理的问题与容易混淆之处

  • 电子 Debye 长度与双组分总屏蔽长度分开；等温单价双组分相差根号二，不按印象统一。
  • 碰撞时间比从显式公式与动量守恒重推，避免沿用来源一处与前式冲突的质量比；动量弛豫与温度交换分别定义。
  • 磁矩的正标量与轨道磁偶极矩矢量分开；磁镜反射保留静电势垒条件。
  • R/L 用有符号回旋频率和明确时间因子定义；冷介电极点不被直接解释为有限吸收功率。
  • 明确标量 MHD 的非相对论、闭合及边界条件；修正一条论文作者误列和能量积分排版。
  • 浏览器检查发现尺度表的绝对值竖线被 Markdown 解析为分栏，已修复；发布检查增加残留公式分隔符与表格列数检查。

复现方法与边界

从仓库根目录，在已安装依赖并生成 _site 后运行：

.venv/bin/python tests/physics_checks.py
.venv/bin/python tests/icrh_checks.py
.venv/bin/python scripts/extract_math.py
node scripts/check_math.mjs
.venv/bin/python scripts/check_site.py _site

基础算例采用 NIST 2022 CODATA 的 SI 常数；指定的 Coulomb 对数是教学输入。引用文献中的不同符号、热速度、磁通及频率定义已经在正文分别说明。强耦合、相对论、简并、非局地输运及具体装置工程条件等超出默认适用域时，应重新选择模型并验证。

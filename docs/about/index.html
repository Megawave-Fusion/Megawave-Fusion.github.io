关于知识库

Megawave-Fusion 聚变知识库，按“原理 → 装置 → 辅助加热 → 腔体材料”的逻辑整理，补充诊断、仿真、工程、实验和文献。

在线阅读：Fusion Stacks · 曦融兆波聚变知识库。

本站参考 Pome 的章节、永久标签、连续阅读与搜索组织方式。Markdown 正文是唯一内容源，网页发布到本仓库 main 分支的 docs/。更新和部署方法见 网站维护。

分类

类目 内容
基础原理 聚变反应、约束、平衡、波与粒子、输运和能量收支
装置路线 托卡马克、场反位形、磁镜、仿星器及其他路线
辅助加热 各套加热与电流驱动系统分别管理
腔体材料 真空室、第一壁、偏滤器、材料、制造与壁面相互作用
诊断控制 诊断方法、标定、数据质量和实时控制
仿真计算 模型、耦合、验证、不确定性与可复现计算
工程系统 磁体、电源、真空、冷却、燃料、屏蔽和维护
实验运行 试验计划、放电记录、验收与故障复盘
项目产业 装置档案、机构、供应链、专利与技术成熟度
文献资料 学习路径、论文、课程、术语和参考来源

辅助加热系统

  • 离子回旋加热（ICRH / ICRF）
  • 电子回旋加热（ECRH / ECCD）
  • 中性束注入（NBI / NBCD）
  • 低杂波电流驱动（LHCD / LHH）
  • 电子伯恩斯坦波加热（EBW）
  • 螺旋波加热（Helicon）

使用方式

每个类目一个主页面，各套辅助加热系统分别一个主页面。直接在页面内的相关章节积累资料，内容增长到确有必要时再拆分文件。

目录采用中文且不加编号；各目录保留 README.md 作为 GitHub 自动展示的首页，正文使用中文，保留必要的专业缩写和原始文献标题。

来源、记录模板和审核要求见 编写说明。等离子体物理已扩为五个正文专题；其他类目继续积累。新增内容的来源、公式和算例复核范围见 核验记录，领域专家审核状态单独保留。

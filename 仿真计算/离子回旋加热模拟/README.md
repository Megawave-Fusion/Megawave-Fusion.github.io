# 离子回旋加热模拟

ICRH 模拟依次连接馈电与天线负载、边缘快波耦合、芯部热全波吸收，以及被加速离子的分布和轨道。先修见[离子回旋加热](../../辅助加热/离子回旋加热/README.md)。

## ICRH 天线负载与匹配：TOPICA、RAPLICASOL 和 HFSS

### 从端口功率到等离子体边界

天线模型先回答各带电流、反射和互耦如何随密度及天线距离变化。输入包括三维导体、法拉第屏、馈电参考面、各端口复振幅，以及天线前的密度和磁场。输出用同一参考阻抗下的 S/Z 矩阵、耦合电阻和局部场表示，再与传输线和匹配网络连接。给每个端口强制相同电流，会得到不同于实际馈电网络的带电流谱；因此谱应从求解后的电流提取。

### 软件承担的环节

TOPICA 将复杂三维天线与等离子体响应连接；RAPLICASOL 采用 COMSOL 有限元、冷磁化张量与吸收边界；HFSS 的作者实现则通过自定义张量计算冷等离子体近场。三者适合比较天线负载与馈电约束。Tierens 等对同一天线几何比较反射、矩阵与匹配，是比直接比较两幅场图更清楚的基准。若目标是芯部少数离子尾分布，还需继续接热波与动理学模型。商业求解器的几何和端口功能不能代替这些等离子体方程的实现。

以同一端口参考面计算净功率时，应保留前向和反向波的复幅度，再将匹配网络变换到该平面。对不同相位方案，记录实际带电流振幅和相位，而不只记录功率源的设定相位；互耦会使二者出现差别。

来源：[Tierens 等 2019，摘要](https://iris.polito.it/handle/11583/2748872)；[Maquet 等 2023，§1–3](https://arxiv.org/html/2309.14015v1)。

## ICRH 组分与发射谱：建立热全波输入

### 将方案落实为组分和边界

热全波输入应记录离子种类、荷质比、密度份额、温度/快尾模型，以及同一时刻的磁平衡和电子剖面。改变少数离子浓度会同时移动混合共振结构、改变极化及功率分配，不能只改一个吸收系数。用天线谱驱动时，需保存各环向模的功率权重；单个环向模结果只代表该谱分量。加热与电流驱动相位也应作为不同输入案例。

### TORIC 与 AORSA 的模型选择

TORIC 采用有限 Larmor 半径展开及径向有限元/极向谱，适合其展开有效的基频、二次谐波和模转换问题。AORSA 保留全阶回旋半径响应，可用于检查高阶谐波和较大回旋半径条件。选择依据是目标粒子的 \(k_\perp\rho_i\)、谐波及几何，而不是“全波”名称。AORSA 官方仓库公开输入 G-EQDSK 和 namelist，并列出 MPI、ScaLAPACK、NetCDF 等依赖；一次可复现比较应保存提交号、组分表、谱权重和相同功率参考面。两套代码不同近似的算例应先做共同有效区比较。

组分扫描还需满足准中性 \(\sum_i Z_i n_i=n_e\)。例如改变氢少数浓度时，主离子密度应同步调整；若固定两者又固定电子密度，会形成不同代码各自修补的非一致输入。磁通坐标和密度单位应在接口文件中显式注明。

来源：[Brambilla 1999，§1–2](https://users.euro-fusion.org/expert/transp/Webpages/files/TORIC.pdf)；[AORSA 官方仓库，Inputs/Dependencies](https://github.com/ORNL-Fusion/aorsa)；[Lau 等，AORSA 模型范围](https://www.ornl.gov/publication/using-aorsa-simulate-helicon-waves-diii-d)。

## ICRH 快波、模转换与各组分吸收

### 区分波支和能量接收者

计算应同时看快波能流、离子–离子混合层附近的转换、短波分支以及电子和各离子的吸收。基频离子吸收、二次谐波吸收、电子 Landau 阻尼和渡越时间磁泵浦对应不同响应；一条总沉积曲线会隐藏功率由哪类粒子接收。比较少数离子、二次谐波及三离子方案时，先保持总注入谱和参考功率一致，再改变组分与频率。

### 短波解析和等效功率汇

TORIC 的原始文献区分完整 FLR 波方程与 ORA：后者将转出的离子 Bernstein 波替换为等效功率汇，可减少解析短波所需的网格。若问题只要求转换份额和较粗沉积，ORA 可作为明确的降阶选项；若问题是短波传播距离、转换后再吸收位置或局部场峰，应保留相应波支并细化网格。冷张量加人为损耗层能让边界出射波离开计算域，但这一损耗不是热离子的物理吸收。两者应分别进入功率账本，避免把边界吸收当成芯部加热。

可将每种离子的直接 RF 吸收记为独立径向剖面，并同时保存天线输入、壁/边界出射和人为损耗项。随后 FP 计算给出的离子向电子碰撞传能再作为另一条通道输出，使“离子吸收占比”与“热电子得到的加热占比”有可追踪的区别。

来源：[Brambilla 1999，§7–10 与 ORA 说明](https://users.euro-fusion.org/expert/transp/Webpages/files/TORIC.pdf)；[Maquet 等 2023，§2–3 吸收边界](https://arxiv.org/html/2309.14015v1)。

## ICRH 快离子尾与 RF–Fokker–Planck 迭代
### 把分布反馈给波场

固定 Maxwell 分布的全波结果给出线性吸收，持续射频加热则可能建立各向异性快尾；快尾又会改变介电响应和阻尼。自洽流程以波场形成速度空间准线性扩散，FP 方程联合碰撞、其他粒子源和损失演化分布，再将分布回传给波求解器。TORIC–CQL3D 的研究强调：波响应采用 FLR 展开时，扩散算子的近似也要相容，才能同时核对功率、偏振和扩散方向。

### 何时补有限轨道

此处 CQL3D 的局部、零轨道宽反弹平均实现把二维动量分布关联到一维径向坐标，适合先求快尾和碰撞传能。若快离子轨道宽度与沉积宽度相当，局部磁面扩散会遗漏跨磁面采样和损失，需要 ORBIT-RF 等轨道方法与全波场连接。验证可从固定 Maxwell 波场、限制粒子保留初始轨道的线性极限开始，再逐项开放轨道和分布反馈。这样可以分清差异来自轨道物理、扩散映射还是波模型；最终背景离子/电子得到的碰撞功率也应与快离子吸收分别输出。

迭代停止条件可同时使用分布函数矩、各组分 RF 功率和快尾能量变化。总功率不变而尾部仍变硬时，碰撞传能和损失预测仍可能在演化；因此总吸收率一个标量不足以定义整个波–粒子系统的稳态。

来源：[Lee 等 2017，§I、IV–V](https://arxiv.org/pdf/1704.07283)；[CQL3D 官方模型说明](https://www.compxco.com/cql3d.html)；[Choi 等，ORBIT-RF/AORSA 线性验证摘要](https://www.ornl.gov/publication/comparison-monte-carlo-ion-cyclotron-heating-model-full-wave-linear-absorption-model)。

### 计算图解

波与分布的接口可写成

$$
P_s^{\rm RF}=\frac12\operatorname{Re}\int_V\mathbf E^*\cdot\mathbf J_s\,dV
=\int_V dV\int d^3v\;\frac{m_sv^2}{2}\,Q_s^{\rm RF}[f_s].
$$

此式采用峰值复幅度，$Q_s^{\rm RF}$ 是对该物种分布的 RF 演化算子；两边对应相同物理近似、体积和功率归一。

## ICRH 网格、谱收敛与测量量对照

### 分开推进数值收敛

波求解至少分别增加径向网格、极向模数和天线环向谱覆盖，跟踪各组分吸收份额、峰位置及积分功率。弱吸收时多次传播和模间耦合使谱需求增加；只看场图平滑不足以认定收敛。天线有限元模型还需改变网格、计算域和吸收层厚度，检查 S 矩阵及参考面功率是否稳定。HFSS 实现中材料张量和时间谐波约定不同，转换错误可能直接改变耗散符号。

### 按测量过程检验

天线端先比反射、带电流或馈电电压，再比耦合电阻随边缘密度的变化；芯部先比调制响应及受热组分，快尾问题再用能谱、快粒子诊断和轨道损失约束。此处建议的验证顺序是：相同几何的端口基准、同一物理近似的波代码比较、分布和轨道前向诊断，最后加入输入不确定性扫描。组分浓度与边缘密度的误差应单独传播，不能用调整一个“有效吸收率”同时拟合所有观测。

代码间比较还可先采用均匀或一维剖面，核对冷波长、极化和无耗散极限的能流；再逐次打开热响应、真实几何和非 Maxwell 分布。每一步保留相同输入，便于把差异定位到新增物理，而非几何或归一化。

来源：[Brambilla 1999，§1 与 §9](https://users.euro-fusion.org/expert/transp/Webpages/files/TORIC.pdf)；[Tierens 等 2019，验证对象](https://iris.polito.it/handle/11583/2748872)；[Maquet 等 2023，§2–4](https://arxiv.org/html/2309.14015v1)。

# 仿真计算

模型、耦合、验证、不确定性与可复现计算。

## 模型与求解器目录

平衡/MHD、全波、射线、Fokker-Planck、轨道/PIC、输运、热结构和中子学。

每个模型列出方程、输入输出、适用尺度、近似和已知失效范围。

## 多物理耦合与数据接口

场—粒子、RF—分布函数、功率沉积—输运、热—结构和边界—壁面。

统一坐标、单位、插值与时间步；通过接口预算检查能量和粒子守恒。

## 验证、确认与不确定性

解析解、制造解、网格/时间步收敛、代码间基准和实验比较。

区分代码是否正确求解方程与模型是否适用于实验；保留误差、置信范围和失败案例。

## 可复现计算

环境、代码提交、输入配置、随机种子、数据版本与输出清单。

保存重跑命令和校验值；文件存在或进程成功不能单独证明计算结论正确。

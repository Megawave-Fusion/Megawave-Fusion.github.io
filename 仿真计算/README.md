# 仿真计算

仿真把物理假设写成方程，再把方程离散为可计算问题。可信结论需要同时说明模型适用范围、数值误差和实验依据。本页核对至 2026-10-16；代码能力只按所读官方文档陈述，未宣称已在本库安装、运行或独立验证这些外部程序。

## 模型与求解器目录

### 先选择尺度，再选择软件

平衡模型回答给定约束下磁面和力平衡如何组织；它不自动给出扰动增长率。MHD 演化描述集体流体行为，依赖单流体、双流体或其他闭合；电阻、粘性及热流模型会影响结果。输运模型描述剖面随时间演化，其通量闭合可以来自经验关系、约化模型或湍流计算，不能一概称为第一性原理预测。模型层级的理论入口见 [MIT 22.611J 课程讲义目录](https://ocw.mit.edu/courses/22-611j-introduction-to-plasma-physics-i-fall-2003/pages/lecture-notes/)，尤其流体、MHD、Vlasov 和波动章节。

动理学模型保留速度分布，能够描述流体矩不足以唯一决定的共振或非热尾部。Gyrokinetic 模型平均去除快回旋相位，以相应磁化、频率和空间尺度排序换取较低计算成本；是否包含电磁扰动、碰撞、大幅剖面变化和有限拉莫尔半径效应必须逐项查证。它不是任意频率波动的通用替代品。例如 [Gkeyll 官方说明](https://gkeyll.readthedocs.io/en/latest/) 的 gyrokinetic 模块明确列出长波长极限下的 full-\(f\) 静电连续动理学求解器；不能把其他分支或论文展示过的能力默认为这个入口的全部功能。

全波求解器保留给定介电响应下的波动结构，射线方法则采用局部波长短于背景变化尺度的近似。是否需要全波取决于截止、模转换、干涉、衍射及边界，而非“全波”名称本身。Fokker–Planck 求解碰撞、源汇和波致扩散作用下的分布演化；热结构求解器把沉积热量转为温度和应力，中子学求解器追踪反应、输运和材料响应。跨模型比较前要核对各自忽略的物理项。

### 有限差分、有限体积与 PIC

有限差分近似网格点上的导数；有限体积对控制体积分，用单元面通量更新体平均量。若内部公共面的通量在相邻单元取同值反号，总和中会相消，这正是离散守恒的重要结构。高阶重构、复杂边界或插值仍可能破坏正性、稳定性或整体守恒，需要单独测试。BOUT++ 官方将自身描述为曲线坐标下的结构化有限差分/体积框架，物理方程由模型指定；示例含流体与湍流模型。参见 [BOUT++ Introduction](https://bout-dev.readthedocs.io/en/stable/user_docs/introduction.html) 和 [Physics models](https://bout-dev.readthedocs.io/en/latest/user_docs/physics_models.html)。使用框架不等于获得已验证的任意方程实现。

PIC 用带权宏粒子表示分布，并在网格上求场。一个循环包含粒子处场插值、粒子推进、电荷/电流沉积和场更新。宏粒子是数值采样对象，不是一对一真实粒子；统计噪声、网格加热、时间步误差和边界处理都影响结论。应分别扫描网格、时间步、每格粒子数和随机种子；显式电磁算法还需满足其稳定性约束。上述算法路径已核对 [Smilei 5.1 PIC algorithms](https://smileipic.github.io/Smilei/Understand/algorithms.html) 的 Quasi-particles、Time and space discretization 与 PIC loop；不同求解器的稳定条件不能混用。

## 多物理耦合与数据接口

### RF—分布函数—输运

射频场给出波粒能量交换和扩散系数；分布函数改变介电响应、碰撞功率和电流；输运改变温度、密度及共振位置。真正的迭代耦合需要把这些更新传回，而不是把一个固定沉积曲线反复传给下游。最小接口应写明物种、坐标、体积元、功率单位、归一化、时间窗和损失口径。

用非相对论动能 \(m_sv^2/2\) 定义 RF 算子贡献时，可检查

\[
P_{\mathrm{RF}\to s}^{\mathrm{FP}}
=\int dV\int d^3v\,\frac{m_sv^2}{2}\,Q_{\mathrm{RF},s}[f_s].
\]

它应与同一物种、同一体积内的波吸收功率一致，精度受离散和耦合残差限制；相对论计算需换成相对论动能，动量坐标需换积分测度。不能通过重复把快离子吸收和快离子对背景的碰撞加热相加，制造额外能量。是否把逃逸粒子和边界通量纳入预算也须明确。

[Frank 等 2022 原论文摘要](https://arxiv.org/abs/2207.09011)报告了 TORLH 与 CQL3D 的功率自洽耦合，并指出其所研究的 C-Mod 情形中，全波修正未解释全部实验差异。本次读取摘要，只引用这一方法与结论边界，不据此断言所有 LHCD 场景都可忽略全波效应。

### 空间和时间映射

磁通坐标中的密度必须与正确体积元配套；归一化极向磁通的平方根和归一化环向磁通不能直接当作同一个半径。保守重映射要求输出网格上的积分与输入预算一致。点值插值看起来平滑，仍可能改变总功率。将二维沉积投影为一维磁面平均会丢失环向和极向结构，应说明这种约化对局部热点或不稳定性是否适用。

耦合时间步需解析被关心的反馈时间尺度。隐式或松弛迭代改善数值收敛，并不能自动证明物理正确；应保存各物种能量残差、粒子残差和迭代变化量，检查更细耦合步长下的目标量是否稳定。这些是本库建议的接口验收条件，不是对某个外部代码已完成验收的声明。

## 验证、确认与不确定性

### 方程实现与物理适用性分开检查

代码验证（verification）检查程序是否正确求解指定方程，可用解析解、守恒恒等式和制造解。制造解先选择光滑函数，再补入使其精确满足方程的源项，因此能检验离散阶数和边界实现，却不是一个真实等离子体实验。BOUT++ 的相应方法证据见 [Dudson 等，Verification of BOUT++ by the Method of Manufactured Solutions](https://arxiv.org/abs/1602.06747)，本次核对作者摘要，不声称复现其测试。

计算验证还要估计本次运行的离散误差。若已处于渐近区间，可检验目标量是否近似满足

\[
Q(h)=Q_\ast+C h^p.
\]

空间加密时同步控制时间误差，时间加密时保持足够细的空间网格。非单调结果、峰值漂移、人工耗散或尚未稳定的时间平均，会使简单阶数估计失效。速度空间范围、波数范围与粒子统计也需要独立扫描；无异常退出不等于收敛。

物理确认（validation）比较模型与实验是否相容。应先用合成诊断把模拟结果经过视线积分、仪器响应和采样处理，再与可观测量比较。调参用的数据和检验预测能力的数据尽量分开，模型之间一致也可能只是共享了同一近似。一个工况通过比较，不能替整个参数空间作保证。

### 不确定性与代理模型

输入不确定性来自测量、材料参数和边界条件；模型形式误差来自缺失机制或闭合；数值误差来自离散与有限采样。先做敏感性分析，识别真正影响目标量的输入，再采用与问题相称的抽样或传播方法；输入相关性应保留，基础传播规则见 [NIST TN 1297 附录 A](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty)。

学习得到的代理模型可以加速扫描，但训练范围、外推检测和约束必须明确。随机打乱同一放电相邻时间点再分训练与测试，可能泄漏高度相关的信息；按独立放电或工况留出更能检验迁移。代理输出满足几个代数约束，不等于已经求解了全部物理方程。

## 可复现计算

一份可复现记录应能回答“用什么方程、什么版本、什么输入得到哪些结果”。本库建议把代码提交、依赖版本、编译选项、机器精度、输入文件、网格、初边值、随机种子、执行命令、输出校验值及分析脚本作为同一运行清单保存。重启计算应记录检查点来源，禁止覆盖原始输入后仍沿用旧标签。

报告以目标量组织：给出网格和时间步敏感性、守恒残差、参数不确定性及适用工况；保留未收敛和失败运行。图片需带物理单位、坐标定义和色标，不能只交一张最漂亮的彩图。跨版本结果变化时先定位方程、数据、数值设置或后处理的变化，再判断物理解释。[BOUT++ Running 文档](https://bout-dev.readthedocs.io/en/latest/user_docs/running_bout.html)说明其输出可记录核心 Git 修订与构建信息；项目自己的模型和输入版本仍需另存。

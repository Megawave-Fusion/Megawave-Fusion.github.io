# 工程系统

磁体、电源、真空、冷却、燃料、屏蔽和维护。

## 磁体与电源

常导/超导磁体、低温、支撑、磁场测绘、电源和保护。

接口包含电流、电压、热负荷、机械载荷及故障状态。

## 真空与气体系统

抽气、管路、阀门、检漏、残余气体、烘烤及运行联锁。

记录工作气体、抽速定义、基底/运行压强、仪表量程和污染控制。

## 冷却与低温

水冷回路、换热、流量/压差、热平衡、低温制冷和监测。

关联真实部件热负荷、冷却介质和材料兼容性；保留传感器与故障响应接口。

## 燃料、注入与循环

气体/丸注入、排气、燃料处理、同位素系统及库存核算。

按装置实际燃料和系统边界归档；氢实验、氘实验和氚相关系统分别标识。

## 屏蔽、维护与运行保障

辐射场计算、屏蔽、可维护性、远程操作、部件更换和检查。

保存设计依据、工况、作业接口与实际评审记录；具体要求引用适用项目文件。

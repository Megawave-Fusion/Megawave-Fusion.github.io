# 腔体材料

真空室、第一壁、偏滤器、材料、制造与壁面相互作用。

## 真空室与腔体结构

壳体、端口、法兰、焊缝、真空密封、烘烤、支撑和载荷。

记录压力、温度循环、真空指标、电磁载荷及接口；材料选择与制造验收分开。

## 第一壁与包层

面向等离子体表面、热沉、连接层、屏蔽和包层功能。

区分装甲层、承力层与功能层；具体材料和包层方案须对应装置版本。

## 偏滤器与排热部件

靶板、热流分布、冷却通道、侵蚀、再沉积与热疲劳。

记录稳态/瞬态热流、润湿面积、循环数、冷却工况；不以熔点代替部件寿命指标。

## 材料数据与选型

钨及合金、铜合金、钢、陶瓷、电绝缘体、涂层、连接材料与候选液态材料。

每份数据记录牌号、加工态、温度、辐照条件、测量方法、单位和不确定性。

## 等离子体与材料相互作用

溅射、反射、滞留、渗透、杂质释放、鞘层和射频增强效应。

将表面状态、入射粒子种类、能谱、角度及通量作为工况记录。

## 制造、连接与检验

机加工、焊接、钎焊、涂层、清洗、无损检测和尺寸计量。

保存工艺版本、样品批次、检验方法与结果；验收限值来自实际项目文件。

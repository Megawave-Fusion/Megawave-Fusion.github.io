# 装置与技术路线

> 状态：初版知识框架，待领域审核 · 更新：2026-09-09

按构型组织共性知识，具体机器使用装置档案；不同路线不默认共用全部模型。

- [托卡马克](tokamak/README.md)：轴对称环形磁约束；分别管理常规与球形托卡马克资料。
- [场反位形 FRC](frc/README.md)：紧凑环形磁拓扑路线，需记录形成、维持与具体场结构。
- [磁镜](mirror/README.md)：开放磁力线约束路线，关注镜场与端部区域。
- [仿星器](stellarator/README.md)：通过外部线圈构建三维约束磁场的路线。
- [其他路线](other-routes/README.md)：反场箍缩 RFP、球马克、Z-pinch、惯性约束和磁惯性约束分别登记。

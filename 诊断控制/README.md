# 诊断控制

诊断方法、标定、数据质量和实时控制。

## 诊断方法

磁测量、干涉、汤姆逊散射、ECE、光谱、辐射、快粒子、中子和壁面红外。

按“被测量 → 仪器 → 反演 → 误差”组织；标明时空分辨率和适用条件。

## 标定与数据质量

零点、增益、时钟、几何、绝对与相对标定。

记录标定标准、日期、漂移、坏道、缺测与反演依赖；原始和处理数据分开存。

## 实时控制与联锁接口

等离子体控制、加热反馈、执行器协调、采集时序和保护接口。

定义信号单位、采样率、延迟、状态机和失效行为；各加热系统保留自己的保护细节。

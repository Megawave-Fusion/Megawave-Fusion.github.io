# 官方来源与检索入口

以下入口于 2026-09-09 检索核对；不是全文系统综述。具体参数需进入原始资料核对版本、工况及正文。

### ITER-HCD

[ITER — External heating systems](https://www.iter.org/machine/supporting-systems/external-heating-systems)

用途：辅助加热概览；装置参数须按具体版本引用。

### IPP-CONFIG

[IPP — Fusionsanlagen](https://www.ipp.mpg.de/9752/anlagentypen)

用途：托卡马克与仿星器概念。

### IAEA-ROUTES

[IAEA — Fusion Technologies](https://nucleus.iaea.org/sites/connect/FUSEpublic/SitePages/Fusion-Technologies.aspx)

用途：聚变路线分类；概览中的发展愿景不作为性能证据。

### IAEA-FFDB

[IAEA — Fusion Facility Database](https://nucleus.iaea.org/sites/fusion-portal/SitePages/FFDB.aspx?web=1)

用途：装置检索入口；本库未批量导入数据库。

### ITER-BLANKET

[ITER — Blanket](https://www.iter.org/machine/blanket)

用途：包层与第一壁工程入口；注意设计版本。

### ITER-DIAG

[ITER — Diagnostics](https://www.iter.org/machine/supporting-systems/diagnostics)

用途：诊断系统入口。

### ITER-SYSTEMS

[ITER — Supporting systems](https://www.iter.org/machine/supporting-systems)

用途：配套工程系统分类。

### ITER-FUEL

[ITER — Fuelling](https://www.iter.org/machine/supporting-systems/fuelling)

用途：燃料与循环子系统。

### IPP-HCD

[IPP — Heating a Fusion Plasma](https://www.ipp.mpg.de/5436011/09_Plasma_Heating.pdf)

用途：加热与电流驱动教学入口。

### STUTTGART-EBW

[University of Stuttgart — Bernstein-wave experiments](https://www.igvp.uni-stuttgart.de/en/research/plasma-dynamics-and-diagnostics/projects/bernstein-wave/)

用途：EBW 与 O-X-B 模转换。

### GA-HELICON

[General Atomics — DIII-D 2018 Long Torus Opening](https://www.ga.com/images/products/energy/magnetic_fusion/DIII-D_APS_3102_1118.pdf)

用途：历史 Helicon 系统方案；不代表当前运行成果。

### IAEA-FRC-NBI

[IAEA FEC 2016 — C-2U FRC sustainment by NBI](https://conferences.iaea.org/event/98/contributions/11670/)

用途：FRC 中 NBI 应用的历史会议摘要。
